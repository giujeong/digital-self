34~37쪽. 33쪽의 巨(클 거)에 손이 붙어 막고(拒), 눈(目) 이야기가 이어져 보고(見) 갖추고(具) 법을 세우고(規) 눈썹(眉)을 그리고 손을 올려 내다본다(看). 그다음은 코 — 코를 본뜬 自(스스로 자)에서 코(鼻), 냄새(臭), 맡기(嗅), 숨(息), 얼굴(面), 머리(首)가 나온다. 마지막은 머리 頁(머리 혈) — 자주(頻), 수염(須), 여름(夏), 근심(憂), 뛰어남(優), 적음(寡).

1. 巨(클 거) 계열 — 33쪽에서 이어짐
   (91) 拒 막을 거 = 扌 + 巨
       音 キョ(きょ) · 訓 こば(む)
       손(扌)을 크게(巨) 벌려 막는다

   A: 会議の提案はどうなりましたか。
      (かいぎのていあんはどうなりましたか)
      회의 제안은 어떻게 됐어요?
   B: 部長に拒否されました。でも、あきらめません。
      (ぶちょうにきょひされました。でも、あきらめません)
      부장님한테 거부당했어요. 그래도 포기 안 해요.

   예문
   - 拒(キョ・きょ) : 彼は取材を拒否しました。
     (かれはしゅざいをきょひしました) 그는 취재를 거부했어요.
   - 拒(こば)む : 子どもが薬を飲むのを拒みます。
     (こどもがくすりをのむのをこばみます) 아이가 약 먹기를 거부해요.

2. 目(눈 목) 계열 — 33쪽에서 이어짐
   (92) 見 볼 견 = 目 + 儿
       音 ケン(けん) · 訓 み(る)・み(える)・み(せる)
       걸어가는 사람(儿) 위에 눈(目)을 크게 — 눈으로 본다
   (93) 具 갖출 구 = 目 + 廾(변형)
       音 グ(ぐ)
       눈(目)이 즐겁도록 두 손으로 받들어(廾) 구색을 갖춘다
   (94) 規 법 규 = 夫 + 見
       音 キ(き)
       어른(夫)이 보는(見) 눈이 곧 법과 같은 규범이 된다
   (95) 眉 눈썹 미 = 尸(눈썹 모양) + 目
       音 ビ(び)・ミ(み) · 訓 まゆ
       눈(目) 위에 난 눈썹을 본뜬 글자. 眉間(みけん) = 눈썹과 눈썹 사이
   (96) 看 볼 간 = 手 + 目
       音 カン(かん)
       눈(目) 위에 손(手)을 올려 햇빛을 가리고 멀리 내다본다

   A: この道具、ちょっと見せてもらえますか。
      (このどうぐ、ちょっとみせてもらえますか)
      이 도구, 좀 보여 주실 수 있어요?
   B: どうぞ。使う前に規則を見てくださいね。
      (どうぞ。つかうまえにきそくをみてくださいね)
      그럼요. 쓰기 전에 규칙을 봐 주세요.

   예문
   - 見(ケン・けん) : 工場を見学しました。
     (こうじょうをけんがくしました) 공장을 견학했어요.
   - 見(み)る : 毎朝ニュースを見ます。
     (まいあさニュースをみます) 매일 아침 뉴스를 봐요.
   - 見(み)える : 窓から富士山が見えます。
     (まどからふじさんがみえます) 창문으로 후지산이 보여요.
   - 見(み)せる : 写真を見せてください。
     (しゃしんをみせてください) 사진을 보여 주세요.
   - 具(グ・ぐ) : 料理の道具をそろえました。
     (りょうりのどうぐをそろえました) 요리 도구를 갖췄어요.
   - 規(キ・き) : 学校の規則を守りましょう。
     (がっこうのきそくをまもりましょう) 학교 규칙을 지킵시다.
   - 眉(ビ・び) : この作品はシリーズの白眉です。
     (このさくひんはシリーズのはくびです) 이 작품은 시리즈의 백미예요.
   - 眉(ミ・み) : 眉間にしわを寄せないで。
     (みけんにしわをよせないで) 미간 찌푸리지 마세요.
   - 眉(まゆ) : 眉を細く描きます。
     (まゆをほそくかきます) 눈썹을 가늘게 그려요.
   - 看(カン・かん) : 姉は病院の看護師です。
     (あねはびょういんのかんごしです) 언니는 병원 간호사예요.

3. 自(스스로 자) 계열
   (97) 自 스스로 자
       音 ジ(じ)・シ(し) · 訓 みずか(ら)
       코를 본뜬 모양. 자기를 가리킬 때 코를 짚으니 '자기 자신'이 됐다
   (98) 鼻 코 비 = 自 + 田 + 廾
       音 ビ(び) · 訓 はな
       밭(田)에서 거둔 음식을 두 손으로 받쳐(廾) 코(自) 앞에 바친다 — 自가 '스스로'로 쓰이자 코는 이 글자가 맡았다
   (99) 臭 냄새 취 = 自 + 大
       音 シュウ(しゅう) · 訓 くさ(い)・にお(う)
       악취가 나면 코(自)가 커진다(大)
   (100) 嗅 맡을 후 = 口 + 臭(自 + 犬)
       音 キュウ(きゅう) · 訓 か(ぐ)
       개(犬)의 코(自) 구멍(口)은 후각이 발달해 냄새를 잘 맡는다
   (101) 息 숨쉴 식 = 自 + 心
       音 ソク(そく) · 訓 いき
       코(自)로 천천히 숨 쉬며 마음(心)을 다스린다 — 쉬다(休息)
   (102) 面 낯 면 = 一 + 自 + 囗
       音 メン(めん) · 訓 おも・おもて・つら
       이마 선(一), 코(自), 얼굴 윤곽(囗)으로 얼굴을 그렸다
   (103) 首 머리 수 = 丷 + 一 + 自
       音 シュ(しゅ) · 訓 くび
       머리숱(丷), 이마 선(一), 코(自)로 머리를 그렸다. 일본어에서는 '목'

   A: なんだか、変なにおいがしますね。
      (なんだか、へんなにおいがしますね)
      어쩐지 이상한 냄새가 나네요.
   B: 本当だ。台所が臭いです。ちょっと息を止めて、鼻を近づけて嗅いでみます。
      (ほんとうだ。だいどころがくさいです。ちょっといきをとめて、はなをちかづけてかいでみます)
      정말이네. 부엌이 냄새나요. 잠깐 숨을 참고 코를 대서 맡아 볼게요.

   예문
   - 自(ジ・じ) : 自分で決めてください。
     (じぶんできめてください) 스스로 정해 주세요.
   - 自(シ・し) : 自然の中を散歩します。
     (しぜんのなかをさんぽします) 자연 속을 산책해요.
   - 自(みずか)ら : 社長自ら説明しました。
     (しゃちょうみずからせつめいしました) 사장님이 직접 설명했어요.
   - 鼻(ビ・び) : 耳鼻科に行きます。
     (じびかにいきます) 이비인후과에 가요.
   - 鼻(はな) : 風邪で鼻が詰まりました。
     (かぜではながつまりました) 감기로 코가 막혔어요.
   - 臭(シュウ・しゅう) : 生ごみの悪臭がします。
     (なまごみのあくしゅうがします) 음식물 쓰레기 악취가 나요.
   - 臭(くさ)い : この靴下は臭いです。
     (このくつしたはくさいです) 이 양말은 냄새나요.
   - 臭(にお)う : ガスが臭います。
     (ガスがにおいます) 가스 냄새가 나요.
   - 嗅(キュウ・きゅう) : 犬は嗅覚が鋭いです。
     (いぬはきゅうかくがするどいです) 개는 후각이 예민해요.
   - 嗅(か)ぐ : 花の香りを嗅ぎます。
     (はなのかおりをかぎます) 꽃향기를 맡아요.
   - 息(ソク・そく) : 少し休息を取りましょう。
     (すこしきゅうそくをとりましょう) 잠깐 휴식을 취합시다.
   - 息(いき) : 深く息を吸ってください。
     (ふかくいきをすってください) 숨을 깊이 들이마셔 주세요.
   - 面(メン・めん) : 来週、面接があります。
     (らいしゅう、めんせつがあります) 다음 주에 면접이 있어요.
   - 面(おも) : 母の面影が残っています。
     (ははのおもかげがのこっています) 어머니의 모습이 남아 있어요.
   - 面(おもて) : 面を上げてください。
     (おもてをあげてください) 고개를 들어 주세요.
   - 面(つら) : いい面構えの選手です。
     (いいつらがまえのせんしゅです) 얼굴이 다부진 선수예요.
   - 首(シュ・しゅ) : 東京は日本の首都です。
     (とうきょうはにほんのしゅとです) 도쿄는 일본의 수도예요.
   - 首(くび) : 寝違えて首が痛いです。
     (ねちがえてくびがいたいです) 잠을 잘못 자서 목이 아파요.

4. 頁(머리 혈, 기본자) 계열
   頁 = 이마 선(一), 코(自), 목(八)으로 그린 머리·얼굴. 夏·憂·寡의 윗부분 百은 頁의 간략형
   (104) 頻 자주 빈 = 歩 + 頁
       音 ヒン(ひん)
       조금만 걸어도(歩) 볼 수 있는 얼굴(頁)이니 자주 만난다 — 빈번
   (105) 須 모름지기 수 = 彡 + 頁
       音 ス(す)
       얼굴(頁)에 수염(彡)이 길게 자랐으면 모름지기 어른이다
   (106) 夏 여름 하 = 百(頁) + 夊
       音 カ(か)・ゲ(げ) · 訓 なつ
       더워서 머리(百)가 뒤로 처지는(夊) 여름
   (107) 憂 근심 우 = 百(頁) + 冖 + 心 + 夊
       音 ユウ(ゆう) · 訓 うれ(える)・うれ(い)・う(い)
       생각(百)이 마음(心)을 덮어(冖) 누르니 모든 것이 뒤처지고(夊) 괴롭다
   (108) 優 뛰어날 우 = 亻 + 憂
       音 ユウ(ゆう) · 訓 やさ(しい)・すぐ(れる)
       근심(憂)이 많은 사람(亻)은 생각이 많고, 생각이 많은 사람은 뛰어나다
   (109) 寡 적을 과 = 宀 + 百(頁) + 分
       音 カ(か)
       집(宀)에 걸린 초상화 속 얼굴(百)은 이승과 나뉜(分) 고인 — 남편이 떠나 집에 사람이 적다. 寡婦(과부)

   A: 夏は苦手ですか。
      (なつはにがてですか)
      여름 싫어해요?
   B: はい、暑いと憂鬱になります。でも夏休みは頻繁に海へ行きますよ。
      (はい、あついとゆううつになります。でもなつやすみはひんぱんにうみへいきますよ)
      네, 더우면 우울해져요. 그래도 여름휴가엔 자주 바다에 가요.

   예문
   - 頻(ヒン・ひん) : このバスは頻繁に来ます。
     (このバスはひんぱんにきます) 이 버스는 자주 와요.
   - 須(ス・す) : 日本語の勉強に辞書は必須です。
     (にほんごのべんきょうにじしょはひっすです) 일본어 공부에 사전은 필수예요.
   - 夏(カ・か) : 夏期講習に参加します。
     (かきこうしゅうにさんかします) 하계 강습에 참가해요.
   - 夏(ゲ・げ) : 今日は夏至です。
     (きょうはげしです) 오늘은 하지예요.
   - 夏(なつ) : 夏休みに旅行します。
     (なつやすみにりょこうします) 여름방학에 여행해요.
   - 憂(ユウ・ゆう) : 雨の日は憂鬱です。
     (あめのひはゆううつです) 비 오는 날은 우울해요.
   - 憂(うれ)える : 国の将来を憂えています。
     (くにのしょうらいをうれえています) 나라의 장래를 걱정하고 있어요.
   - 憂(うれ)い : 後顧の憂いがないように準備します。
     (こうこのうれいがないようにじゅんびします) 뒷걱정이 없도록 준비해요.
   - 憂(う)い : 物憂い午後です。
     (ものういごごです) 나른한 오후예요.
   - 優(ユウ・ゆう) : 日本チームが優勝しました。
     (にほんチームがゆうしょうしました) 일본 팀이 우승했어요.
   - 優(やさ)しい : 先生はとても優しいです。
     (せんせいはとてもやさしいです) 선생님은 아주 상냥해요.
   - 優(すぐ)れる : この製品は性能が優れています。
     (このせいひんはせいのうがすぐれています) 이 제품은 성능이 뛰어나요.
   - 寡(カ・か) : 父は寡黙な人です。
     (ちちはかもくなひとです) 아버지는 과묵한 사람이에요.

포인트
   拒 = 扌 + 巨 — 33쪽 巨·距에 이어 巨 가족 셋. 拒否(きょひ)·拒む(こばむ)
   見 가족 : 見(み)る·見(み)える·見(み)せる — 보다·보이다·보여주다. 規는 夫 + 見
   눈 둘 구별 : 見(눈 + 걷는 사람) / 看(눈 + 손). 看護師(かんごし)·看板(かんばん)
   自 = 코. 自가 '스스로'가 되자 코는 鼻(び·はな)가 맡았다. 自 읽기 ジ·シ — 自分(じぶん) / 自然(しぜん)
   臭와 嗅 : 臭(くさい, シュウ)는 일본 자형이 自 + 大, 嗅(かぐ, キュウ) 안에서는 自 + 犬
   息子(むすこ, 아들)는 통째로 읽는 특수 읽기
   面 おも는 面白い(おもしろい, 재미있다)에서 자주 본다
   首(くび)는 일본어에서 '목'. 머리는 頭(あたま)
   頁 = 일본에서는 ページ(쪽)로 읽는다 — 10頁 = じゅっページ
   憂 → 優 : 근심(憂)에 사람(亻)이 붙으면 뛰어남(優). 둘 다 ユウ
   夏 ゲ는 夏至(げし, 하지)에서. 寡는 寡黙(かもく, 과묵)·寡婦(かふ, 과부)
   반의어 : 夏 ↔ 冬 / 優 ↔ 劣 / 寡 ↔ 多
   읽기가 여러 개인 글자 — 拒 キョ·こばむ / 見 ケン·みる·みえる·みせる / 眉 ビ·ミ·まゆ / 自 ジ·シ·みずから / 鼻 ビ·はな / 臭 シュウ·くさい·におう / 嗅 キュウ·かぐ / 息 ソク·いき / 面 メン·おも·おもて·つら / 首 シュ·くび / 夏 カ·ゲ·なつ / 憂 ユウ·うれえる·うれい·うい / 優 ユウ·やさしい·すぐれる
