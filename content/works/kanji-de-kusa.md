1. 屮(싹날 철, 기본자) 계열
   屮 = 싹이 돋아난 모습
   (1) 出 날 출 = 凵 + 屮
       音 シュツ(しゅつ)・スイ(すい) · 訓 で(る)・だ(す)
       화분(凵)에 씨앗을 심어 두었더니 싹(屮)이 나왔다
   (2) 拙 옹졸할 졸 = 扌 + 出
       音 セツ(せつ) · 訓 つたな(い)
       졸장부처럼 나간(出) 것을 다시 달라고 손(扌)을 내민다

   A: 出口はどこですか。
      (でぐちはどこですか)
      출구가 어디예요?
   B: あそこです。拙い字ですが、地図を書きますね。
      (あそこです。つたないじですが、ちずをかきますね)
      저쪽이에요. 서툰 글씨지만 지도를 그려 드릴게요.

   예문
   - 出(で)る : 毎朝七時に家を出ます。
     (まいあさしちじにいえをでます) 매일 아침 7시에 집을 나서요.
   - 出(だ)す : 手紙を出しました。
     (てがみをだしました) 편지를 부쳤어요.
   - 出(シュツ・しゅつ) : 明日、出発します。
     (あした、しゅっぱつします) 내일 출발해요.
   - 出(スイ・すい) : 出納係 (すいとうがかり) 출납 담당
   - 拙(つたな)い : 拙い日本語ですが、よろしくお願いします。
     (つたないにほんごですが、よろしくおねがいします) 서툰 일본어지만 잘 부탁드려요.
   - 拙(セツ・せつ) : 稚拙な文章ですみません。
     (ちせつなぶんしょうですみません) 서툰 문장이라 죄송해요.

2. 艹(풀 초) 계열
   (1) 草 풀 초 = 艹 + 早  (복습)
       音 ソウ(そう) · 訓 くさ
       풀은 빨리(早) 자라고 빨리 시든다
   (2) 芯 등심초 심 = 艹 + 心
       音 シン(しん)
       마음(心)의 불안을 다스리는 약초 — 등잔의 심지로도 쓰임
   (3) 若 젊을 약 = 艹 + 右
       音 ジャク(じゃく)・ニャク(にゃく) · 訓 わか(い)・も(しくは)
       손(右)으로 머리카락(艹)을 만지는, 외모에 신경 쓰는 젊은이
   (4) 諾 허락할 낙 = 言 + 若
       音 ダク(だく)
       젊은(若) 사람이 말(言)을 예쁘게 하니 허락한다
   (5) 葉 잎 엽 = 艹 + 世 + 木
       音 ヨウ(よう) · 訓 は
       나무(木)에서 뻗은 가지(世), 그 가지에서 나온 잎(艹)

   A: 紅葉を見に行きませんか。
      (こうようをみにいきませんか)
      단풍 보러 가지 않을래요?
   B: はい、喜んで。若い頃はよく山に登りました。
      (はい、よろこんで。わかいころはよくやまにのぼりました)
      네, 좋아요. 젊었을 때는 산에 자주 올랐어요.

   예문
   - 草(くさ) : 庭の草を取りました。
     (にわのくさをとりました) 마당의 풀을 뽑았어요.
   - 草(ソウ・そう) : 広い草原を歩きました。
     (ひろいそうげんをあるきました) 넓은 초원을 걸었어요.
   - 芯(シン・しん) : 鉛筆の芯が折れました。
     (えんぴつのしんがおれました) 연필심이 부러졌어요.
   - 若(わか)い : この町は若い人が多いですね。
     (このまちはわかいひとがおおいですね) 이 동네는 젊은 사람이 많네요.
   - 若(ジャク・じゃく) : 予定に若干の変更があります。
     (よていにじゃっかんのへんこうがあります) 일정에 약간의 변경이 있어요.
   - 若(ニャク・にゃく) : 老若男女 (ろうにゃくなんにょ) 남녀노소
   - 諾(ダク・だく) : 先生が快く承諾してくれました。
     (せんせいがこころよくしょうだくしてくれました) 선생님이 흔쾌히 승낙해 주셨어요.
   - 葉(は) : 木の葉が赤くなりました。
     (きのはがあかくなりました) 나뭇잎이 빨개졌어요.
   - 葉(ヨウ・よう) : 紅葉がきれいです。
     (こうようがきれいです) 단풍이 예뻐요.

3. 자연을 본뜬 글자
   (1) 山 뫼 산
       音 サン(さん) · 訓 やま
       산의 모양을 본뜸
   (2) 水 물 수 (변으로 쓰면 氵)
       音 スイ(すい) · 訓 みず
       물이 흘러가는 모양

   A: 山の水はおいしいですか。
      (やまのみずはおいしいですか)
      산의 물은 맛있어요?
   B: はい、冷たくてとてもおいしいです。
      (はい、つめたくてとてもおいしいです)
      네, 차갑고 아주 맛있어요.

   예문
   - 山(やま) : 週末に山に登ります。
     (しゅうまつにやまにのぼります) 주말에 산에 올라요.
   - 山(サン・さん) : ここから富士山が見えます。
     (ここからふじさんがみえます) 여기서 후지산이 보여요.
   - 水(みず) : 水を一杯ください。
     (みずをいっぱいください) 물 한 잔 주세요.
   - 水(スイ・すい) : 水曜日に会いましょう。
     (すいようびにあいましょう) 수요일에 만나요.

포인트
   草 ソウ = 早 ソウ — 빨리(早) 자라는 풀이라 소리도 같다
   若 ジャク → 諾 ダク — 若이 들어가도 소리는 바뀐다
   出 シュツ → 拙 セツ — 出이 들어가도 소리는 바뀐다
