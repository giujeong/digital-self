38~41쪽. 귀를 본뜬 耳(귀 이)에서 시작해 손에 쥐고(取), 뜻을 향해 달려가고(趣), 가장(最) 좋은 순간을 찍는다(撮). 귀에 마음이 붙으면 부끄럽고(恥) 귀 기울여 듣는다(聴). 그다음은 심장을 본뜬 心(마음 심) — 꺼리고(忌), 공손하고(恭), 두려워하고(惧), 닦고(修), 멀다(悠). 마지막은 달 月(달 월) — 저녁(夕), 그리고 왼쪽·아래로 가면 고기(肉)가 되는 月: 많다(多), 옳게 여기다(肯), 있다(有), 팔꿈치(肘).

1. 耳(귀 이) 계열
   (110) 耳 귀 이
       音 ジ(じ) · 訓 みみ
       귀의 모양을 본뜬 글자
   (111) 取 가질 취 = 耳 + 又
       音 シュ(しゅ) · 訓 と(る)
       싸움에서 공을 세운 증거로 적의 귀(耳)를 잘라 손(又)에 쥔다
   (112) 趣 뜻 취 = 走 + 取
       音 シュ(しゅ) · 訓 おもむき
       손에 넣으려고(取) 달려간다(走) — 마음이 향하는 곳, 뜻
   (113) 最 가장 최 = 日 + 取
       音 サイ(さい) · 訓 もっと(も)
       귀(取)를 가장 많이 거둔 날(日) — 최고
   (114) 撮 사진찍을 촬 = 扌 + 最
       音 サツ(さつ) · 訓 と(る)
       손(扌)으로 셔터를 눌러 최고(最)의 순간을 담는다
   (115) 恥 부끄러울 치 = 耳 + 心
       音 チ(ち) · 訓 は(じる)・はじ・は(じらう)・は(ずかしい)
       부끄러우면 귀(耳)가 빨개진다 — 귀로 드러나는 마음(心)
   (116) 聴 들을 청 = 耳 + 十 + 目(罒) + 心
       音 チョウ(ちょう) · 訓 き(く)
       귀(耳)로 많이(十) 듣고 눈(罒)으로 보며 마음(心)으로 공감하는 것이 듣는 것

   A: 趣味は何ですか。
      (しゅみはなんですか)
      취미가 뭐예요?
   B: 写真を撮ることです。最近は寝る前に音楽も聴きます。
      (しゃしんをとることです。さいきんはねるまえにおんがくもききます)
      사진 찍는 거예요. 요즘엔 자기 전에 음악도 들어요.

   예문
   - 耳(ジ・じ) : 子どもが中耳炎になりました。
     (こどもがちゅうじえんになりました) 아이가 중이염에 걸렸어요.
   - 耳(みみ) : 祖父は耳が遠いです。
     (そふはみみがとおいです) 할아버지는 귀가 어두워요.
   - 取(シュ・しゅ) : 新聞記者が取材に来ました。
     (しんぶんきしゃがしゅざいにきました) 신문기자가 취재하러 왔어요.
   - 取(と)る : 塩を取ってください。
     (しおをとってください) 소금 좀 집어 주세요.
   - 趣(シュ・しゅ) : 私の趣味は料理です。
     (わたしのしゅみはりょうりです) 제 취미는 요리예요.
   - 趣(おもむき) : この庭は趣があります。
     (このにわはおもむきがあります) 이 정원은 운치가 있어요.
   - 最(サイ・さい) : 最近、仕事が忙しいです。
     (さいきん、しごとがいそがしいです) 요즘 일이 바빠요.
   - 最(もっと)も : 富士山は日本で最も高い山です。
     (ふじさんはにほんでもっともたかいやまです) 후지산은 일본에서 가장 높은 산이에요.
   - 撮(サツ・さつ) : 来月、映画の撮影があります。
     (らいげつ、えいがのさつえいがあります) 다음 달에 영화 촬영이 있어요.
   - 撮(と)る : 一緒に写真を撮りましょう。
     (いっしょにしゃしんをとりましょう) 같이 사진 찍어요.
   - 恥(チ・ち) : 彼には羞恥心がないようです。
     (かれにはしゅうちしんがないようです) 그에게는 수치심이 없는 것 같아요.
   - 恥(は)じる : 自分の行いを恥じています。
     (じぶんのおこないをはじています) 제 행동을 부끄러워하고 있어요.
   - 恥(はじ) : 人前で恥をかきました。
     (ひとまえではじをかきました) 사람들 앞에서 창피를 당했어요.
   - 恥(は)じらう : 花嫁が恥じらって笑いました。
     (はなよめがはじらってわらいました) 신부가 수줍게 웃었어요.
   - 恥(は)ずかしい : 名前を間違えて恥ずかしいです。
     (なまえをまちがえてはずかしいです) 이름을 틀려서 부끄러워요.
   - 聴(チョウ・ちょう) : 日本語の聴解が苦手です。
     (にほんごのちょうかいがにがてです) 일본어 청해가 약해요.
   - 聴(き)く : 寝る前に音楽を聴きます。
     (ねるまえにおんがくをききます) 자기 전에 음악을 들어요.

2. 心(마음 심) 계열
   (117) 心 마음 심
       音 シン(しん) · 訓 こころ
       사람의 심장을 본뜬 글자. 변으로 쓰면 忄, 아래에 깔리면 ⺗
   (118) 忌 꺼릴 기 = 己 + 心
       音 キ(き) · 訓 い(む)・い(まわしい)
       기어가는 뱀 같은 己를 보면 꺼리는 마음(心)이 든다 — 기분이 안 좋다
   (119) 恭 공손할 공 = 共 + ⺗
       音 キョウ(きょう) · 訓 うやうや(しい)
       함께(共) 마음(⺗)을 모아 공손하게 인사한다
   (120) 惧 두려워할 구 = 忄 + 具
       音 グ(ぐ)
       음식을 갖추어(具) 두려운 마음(忄)으로 신께 바친다
   (121) 修 닦을 수 = 亻 + 丨 + 攵 + 彡
       音 シュウ(しゅう)・シュ(しゅ) · 訓 おさ(める)・おさ(まる)
       스승(亻)이 회초리(丨)를 들어 치는(攵) 것은 제자가 바르게 닦아 빛나도록(彡) 하기 위해서
   (122) 悠 멀 유 = 亻 + 丨 + 攵 + 心
       音 ユウ(ゆう)
       스승(亻)에게 매(丨)를 맞은(攵) 제자의 마음(心) — 수행의 길은 참 멀다

   A: 明日の発表、心配です。
      (あしたのはっぴょう、しんぱいです)
      내일 발표가 걱정돼요.
   B: 失敗を忌むより、悠々と構えましょう。修行だと思えばいいですよ。
      (しっぱいをいむより、ゆうゆうとかまえましょう。しゅぎょうだとおもえばいいですよ)
      실패를 꺼리기보다 느긋하게 마음먹어요. 수행이라고 생각하면 돼요.

   예문
   - 心(シン・しん) : 心配しないでください。
     (しんぱいしないでください) 걱정하지 마세요.
   - 心(こころ) : 心を込めて手紙を書きました。
     (こころをこめててがみをかきました) 마음을 담아 편지를 썼어요.
   - 忌(キ・き) : 明日は祖父の一周忌です。
     (あしたはそふのいっしゅうきです) 내일은 할아버지 1주기예요.
   - 忌(い)む : 四という数字を忌む人もいます。
     (しというすうじをいむひともいます) 4라는 숫자를 꺼리는 사람도 있어요.
   - 忌(い)まわしい : 忌まわしい事件を早く忘れたいです。
     (いまわしいじけんをはやくわすれたいです) 끔찍한 사건을 빨리 잊고 싶어요.
   - 恭(キョウ・きょう) : 年賀状に恭賀新年と書きました。
     (ねんがじょうにきょうがしんねんとかきました) 연하장에 공하신년이라고 썼어요.
   - 恭(うやうや)しい : 彼は恭しく頭を下げました。
     (かれはうやうやしくあたまをさげました) 그는 공손하게 고개를 숙였어요.
   - 惧(グ・ぐ) : トキは絶滅危惧種です。
     (ときはぜつめつきぐしゅです) 따오기는 멸종위기종이에요.
   - 修(シュウ・しゅう) : 車を修理に出しました。
     (くるまをしゅうりにだしました) 차를 수리 맡겼어요.
   - 修(シュ・しゅ) : 若いころ、山で修行しました。
     (わかいころ、やまでしゅぎょうしました) 젊을 때 산에서 수행했어요.
   - 修(おさ)める : 大学で経済学を修めました。
     (だいがくでけいざいがくをおさめました) 대학에서 경제학을 이수했어요.
   - 修(おさ)まる : 結婚してから素行が修まりました。
     (けっこんしてからそこうがおさまりました) 결혼하고 나서 품행이 바로잡혔어요.
   - 悠(ユウ・ゆう) : 定年後は悠々と暮らしています。
     (ていねんごはゆうゆうとくらしています) 정년 후에는 느긋하게 지내요.

3. 月(달 월) 계열
   (123) 月 달 월
       音 ゲツ(げつ)・ガツ(がつ) · 訓 つき
       초승달 모양을 본뜬 글자. 오른쪽에 오면 달, 왼쪽이나 아래에 오면 고기(肉)·몸 — 육달 월
   (124) 夕 저녁 석
       音 セキ(せき) · 訓 ゆう
       月에서 획 하나가 빠진, 막 떠오르기 시작한 달 — 해가 지고 달이 뜨기까지의 저녁
   (125) 肉 고기 육
       音 ニク(にく)
       살코기와 지방층을 그린 고기. 부수로 쓰면 月과 모양이 같아 '육달 월'
   (126) 多 많을 다 = 夕 + 夕
       音 タ(た) · 訓 おお(い)
       고기(肉) 두 덩어리를 쌓았으니 많다 — 모양은 夕 둘
   (127) 肯 옳게여길 긍 = 止 + 月
       音 コウ(こう)
       몸(月)의 욕망을 멈추는(止) 것 — 그것을 옳게 여긴다
   (128) 有 있을 유 = ナ + 月
       音 ユウ(ゆう)・ウ(う) · 訓 あ(る)
       손(ナ)에 고기(月)가 있다
   (129) 肘 팔꿈치 주 = 月 + 寸
       訓 ひじ
       몸(月)의 마디(寸) 가운데 손과 관련된 가장 큰 마디

   A: 今月は夕食に肉が多いですね。
      (こんげつはゆうしょくににくがおおいですね)
      이번 달은 저녁에 고기가 많네요.
   B: 近くに有名な肉屋ができたんです。
      (ちかくにゆうめいなにくやができたんです)
      근처에 유명한 정육점이 생겼거든요.

   예문
   - 月(ゲツ・げつ) : 月曜日に会いましょう。
     (げつようびにあいましょう) 월요일에 만나요.
   - 月(ガツ・がつ) : 四月から日本で働きます。
     (しがつからにほんではたらきます) 4월부터 일본에서 일해요.
   - 月(つき) : 今夜は月がきれいです。
     (こんやはつきがきれいです) 오늘 밤은 달이 예뻐요.
   - 夕(セキ・せき) : 日本語は一朝一夕には上手になりません。
     (にほんごはいっちょういっせきにはじょうずになりません) 일본어는 하루아침에 늘지 않아요.
   - 夕(ゆう) : 夕方に散歩します。
     (ゆうがたにさんぽします) 저녁 무렵에 산책해요.
   - 肉(ニク・にく) : 晩ご飯に肉を焼きます。
     (ばんごはんににくをやきます) 저녁밥으로 고기를 구워요.
   - 多(タ・た) : 多分、明日は雨です。
     (たぶん、あしたはあめです) 아마 내일은 비예요.
   - 多(おお)い : 東京は人が多いです。
     (とうきょうはひとがおおいです) 도쿄는 사람이 많아요.
   - 肯(コウ・こう) : 彼は私の意見を肯定しました。
     (かれはわたしのいけんをこうていしました) 그는 제 의견을 긍정했어요.
   - 有(ユウ・ゆう) : このお寺はとても有名です。
     (このおてらはとてもゆうめいです) 이 절은 아주 유명해요.
   - 有(ウ・う) : 参加の有無を教えてください。
     (さんかのうむをおしえてください) 참가 여부를 알려 주세요.
   - 有(あ)る : 時間は有り余るほどあります。
     (じかんはありあまるほどあります) 시간은 남아돌 만큼 있어요.
   - 肘(ひじ) : 机に肘をつかないでください。
     (つくえにひじをつかないでください) 책상에 팔꿈치를 괴지 마세요.

포인트
   取 가족 : 取(シュ)·趣(シュ)·最(サイ)·撮(サツ) — 모두 取를 품고 있다
   取る와 撮る는 둘 다 とる — 잡다·집다 / (사진을) 찍다
   恥·聴 = 耳 + 心. 恥ずかしい(はずかしい, 부끄럽다)는 꼭 외우기
   聴く와 聞く : 聴く는 귀 기울여 듣기(음악·강의), 聞く는 들리다·묻다
   心 세 모양 : 心(그대로) / 忄(변, 惧) / ⺗(발, 恭)
   惧는 상용 읽기 グ 하나 — 危惧(きぐ, 걱정·우려)
   修·悠 : 亻 丨 攵 공통 — 닦는 길(修 シュウ)은 멀다(悠 ユウ)
   月 두 얼굴 : 오른쪽 月 = 달 / 왼쪽·아래 月 = 고기·몸(육달 월) — 肘·肯·有
   月 읽기 : 月曜日(げつようび) · 四月(しがつ) · 月(つき)
   夕 : 夕方(ゆうがた) · 七夕(たなばた, 칠석 — 통째로 읽는 특수 읽기)
   多 = 夕 + 夕 — 책 풀이는 고기 두 덩어리
   반의어 : 取 ↔ 捨 / 多 ↔ 少 / 肯 ↔ 否 / 有 ↔ 無 / 夕 ↔ 朝
   읽기가 여러 개인 글자 — 耳 ジ·みみ / 取 シュ·とる / 趣 シュ·おもむき / 最 サイ·もっとも / 撮 サツ·とる / 恥 チ·はじる·はじ·はじらう·はずかしい / 聴 チョウ·きく / 心 シン·こころ / 忌 キ·いむ·いまわしい / 恭 キョウ·うやうやしい / 修 シュウ·シュ·おさめる·おさまる / 月 ゲツ·ガツ·つき / 夕 セキ·ゆう / 多 タ·おおい / 有 ユウ·ウ·ある
