42~45쪽. 41쪽에서 이어진 月(달 월) 계열 — 해와 달이 함께 있어 밝고(明), 죄인 몸에 새긴 문양이 옷(服)이 되고, 몸 한가운데 척추(脊)가 서고, 고기를 두드리면 흩어진다(散). 둥근 원을 그린 円(둥글 원)을 지나 해를 본뜬 日(날 일) — 등잔불 白(흰 백), 두 해 아래 노래하고(唱), 세 해가 모여 맑고(晶), 해의 한결같은 걸음은 옳다(是). 是가 붙으면 끌어당기고(提), 둑을 쌓고(堤), 제목이 된다(題). 두 사내가 근무를 바꾸고(替), 큰물에 잠긴다(潜). 마지막은 땅 위로 해가 뜨는 旦(아침 단) — 이르고(早), 풀이 자라고(草), 다만(但), 짐을 메고 나선다(担).

1. 月(달 월) 계열 — 41쪽에서 이어짐
   (130) 明 밝을 명 = 日 + 月
       音 メイ(めい)・ミョウ(みょう) · 訓 あ(かり)・あか(るい)・あか(るむ)・あか(らむ)・あき(らか)・あ(ける)・あ(く)・あ(くる)・あ(かす)
       해(日)와 달(月)이 함께 있으니 밝다
   (131) 服 옷 복 = 月 + 卩 + 又
       音 フク(ふく)
       붙잡힌(又) 죄인(卩)의 몸(月)에 새긴 문양 — 무늬를 넣은 옷이 되었다. 죄인은 복종(服従)해야 한다
   (132) 脊 등마루 척 = 人 + == + 月
       音 セキ(せき)
       사람(人)의 몸(月), 평평한 등(==) 한가운데 뼈마디가 툭 솟아 있는 척추
   (133) 散 흩을 산 = 𣏟 + 月 + 攵
       音 サン(さん) · 訓 ち(る)・ち(らす)・ち(らかす)・ち(らかる)
       삼베(𣏟)를 두드리듯 고기(月)를 치면(攵) 펴지면서 산산이 흩어진다. 위쪽은 𣏟를 줄인 모양

   A: 明日は明るい服を着て散歩しませんか。
      (あしたはあかるいふくをきてさんぽしませんか)
      내일 밝은 옷 입고 산책하지 않을래요?
   B: いいですね。夜が明けたらすぐ出かけましょう。
      (いいですね。よるがあけたらすぐでかけましょう)
      좋아요. 날이 밝으면 바로 나가요.

   예문
   - 明(メイ・めい) : 先生が文法を説明しました。
     (せんせいがぶんぽうをせつめいしました) 선생님이 문법을 설명했어요.
   - 明(ミョウ・みょう) : 明日の午前中に伺います。
     (みょうにちのごぜんちゅうにうかがいます) 내일 오전 중에 찾아뵙겠습니다.
   - 明(あ)かり : 部屋の明かりを消してください。
     (へやのあかりをけしてください) 방 불을 꺼 주세요.
   - 明(あか)るい : この部屋は明るいです。
     (このへやはあかるいです) 이 방은 밝아요.
   - 明(あか)るむ : 東の空が明るんできました。
     (ひがしのそらがあかるんできました) 동쪽 하늘이 밝아 오기 시작했어요.
   - 明(あか)らむ : 夜明け前に空が明らみました。
     (よあけまえにそらがあからみました) 날이 새기 전에 하늘이 훤해졌어요.
   - 明(あき)らか : 事故の原因は明らかです。
     (じこのげんいんはあきらかです) 사고 원인은 분명해요.
   - 明(あ)ける : もうすぐ夜が明けます。
     (もうすぐよるがあけます) 곧 날이 밝아요.
   - 明(あ)く : 子犬の目がやっと明きました。
     (こいぬのめがやっとあきました) 강아지 눈이 드디어 떠졌어요.
   - 明(あ)くる : 明くる日、雨が止みました。
     (あくるひ、あめがやみました) 이튿날 비가 그쳤어요.
   - 明(あ)かす : 友だちに秘密を明かしました。
     (ともだちにひみつをあかしました) 친구에게 비밀을 털어놨어요.
   - 服(フク・ふく) : 新しい服を買いました。
     (あたらしいふくをかいました) 새 옷을 샀어요.
   - 脊(セキ・せき) : 脊髄は大切な神経です。
     (せきずいはたいせつなしんけいです) 척수는 중요한 신경이에요.
   - 散(サン・さん) : 夕方に公園を散歩しました。
     (ゆうがたにこうえんをさんぽしました) 저녁 무렵 공원을 산책했어요.
   - 散(ち)る : 桜の花が散りました。
     (さくらのはながちりました) 벚꽃이 졌어요.
   - 散(ち)らす : 風が落ち葉を散らしました。
     (かぜがおちばをちらしました) 바람이 낙엽을 흩뜨렸어요.
   - 散(ち)らかす : 子どもがおもちゃを散らかしました。
     (こどもがおもちゃをちらかしました) 아이가 장난감을 어질렀어요.
   - 散(ち)らかる : 部屋が散らかっています。
     (へやがちらかっています) 방이 어질러져 있어요.

2. 모양을 본뜬 글자 — 円
   (134) 円 둥글 원
       音 エン(えん) · 訓 まる(い)
       물체의 지름과 반지름을 그어 둥근 원을 나타냈다. 일본 돈의 단위(엔)로도 쓴다

   예문
   - 円(エン・えん) : このパンは百円です。
     (このパンはひゃくえんです) 이 빵은 100엔이에요.
   - 円(まる)い : 円いテーブルを買いました。
     (まるいテーブルをかいました) 둥근 탁자를 샀어요.

3. 日(날 일) 계열
   (135) 日 날 일
       音 ニチ(にち)・ジツ(じつ) · 訓 ひ・か
       해의 모양을 본뜬 글자(갑골문). 부품으로 들어가면 해·날·빛
   (136) 白 흰 백
       音 ハク(はく)・ビャク(びゃく) · 訓 しろ・しら・しろ(い)
       등잔불을 그린 글자 — 불을 켜니 어두웠던 방이 하얗게 밝아졌다. 희다·밝다·깨끗하다
   (137) 唱 부를 창 = 口 + 昌
       音 ショウ(しょう) · 訓 とな(える)
       동해물과 백두산 위로 떠오른 두 해(昌) — 입(口)으로 애국가를 부른다
   (138) 晶 맑을 정 = 日 + 日 + 日
       音 ショウ(しょう)
       세 빛(日)이 모여 흰빛이 되니 수정처럼 맑다
   (139) 是 옳을 시 = 日 + 疋
       音 ゼ(ぜ)
       해(日)는 한결같이 걸어가니(疋) 해시계는 정확하다 — 옳다

   A: 合唱の練習は何時からですか。
      (がっしょうのれんしゅうはなんじからですか)
      합창 연습은 몇 시부터예요?
   B: 日曜日の午後です。白いシャツを着て、是非来てくださいね。
      (にちようびのごごです。しろいシャツをきて、ぜひきてくださいね)
      일요일 오후예요. 흰 셔츠 입고 꼭 와 주세요.

   예문
   - 日(ニチ・にち) : 毎日、漢字を三つ覚えます。
     (まいにち、かんじをみっつおぼえます) 매일 한자를 세 개 외워요.
   - 日(ジツ・じつ) : 本日は休業です。
     (ほんじつはきゅうぎょうです) 오늘은 휴업이에요.
   - 日(ひ) : 日が長くなりました。
     (ひがながくなりました) 해가 길어졌어요.
   - 日(か) : 三日後に会いましょう。
     (みっかごにあいましょう) 사흘 뒤에 만나요.
   - 白(ハク・はく) : 白紙に名前を書いてください。
     (はくしになまえをかいてください) 백지에 이름을 써 주세요.
   - 白(ビャク・びゃく) : 北欧では夏に白夜があります。
     (ほくおうではなつにびゃくやがあります) 북유럽에는 여름에 백야가 있어요.
   - 白(しろ) : 白と黒の猫がいます。
     (しろとくろのねこがいます) 흰색과 검은색 고양이가 있어요.
   - 白(しら) : 最近、白髪が増えました。
     (さいきん、しらがふえました) 요즘 흰머리가 늘었어요.
   - 白(しろ)い : 白い雲が浮かんでいます。
     (しろいくもがうかんでいます) 흰 구름이 떠 있어요.
   - 唱(ショウ・しょう) : 教会で合唱しました。
     (きょうかいでがっしょうしました) 교회에서 합창했어요.
   - 唱(とな)える : 毎朝、祈りの言葉を唱えます。
     (まいあさ、いのりのことばをとなえます) 매일 아침 기도문을 읊어요.
   - 晶(ショウ・しょう) : 水晶のネックレスをもらいました。
     (すいしょうのネックレスをもらいました) 수정 목걸이를 받았어요.
   - 是(ゼ・ぜ) : 是非、遊びに来てください。
     (ぜひ、あそびにきてください) 꼭 놀러 오세요.

4. 是(옳을 시) 계열
   (140) 提 끌 제 = 扌 + 是
       音 テイ(てい) · 訓 さ(げる)
       손(扌)으로 옳은(是) 것을 끌어당겨 제 것으로 삼는다
   (141) 堤 둑 제 = 土 + 是
       音 テイ(てい) · 訓 つつみ
       물이 바르게(是) 흐르도록 흙(土)으로 쌓은 제방
   (142) 題 제목 제 = 是 + 頁
       音 ダイ(だい)
       글의 내용을 바르게(是) 드러내는 얼굴(頁) — 제목

   A: レポートの題は決まりましたか。
      (レポートのだいはきまりましたか)
      리포트 제목은 정했어요?
   B: はい。明日までに提出します。
      (はい。あしたまでにていしゅつします)
      네. 내일까지 제출할게요.

   예문
   - 提(テイ・てい) : 宿題を提出しました。
     (しゅくだいをていしゅつしました) 숙제를 제출했어요.
   - 提(さ)げる : 重いかばんを提げて歩きました。
     (おもいかばんをさげてあるきました) 무거운 가방을 들고 걸었어요.
   - 堤(テイ・てい) : 大雨で堤防が壊れました。
     (おおあめでていぼうがこわれました) 큰비에 제방이 무너졌어요.
   - 堤(つつみ) : 川の堤を散歩しました。
     (かわのつつみをさんぽしました) 강둑을 산책했어요.
   - 題(ダイ・だい) : 今日の話題は天気です。
     (きょうのわだいはてんきです) 오늘의 화제는 날씨예요.

5. 替 · 潜
   (143) 替 바꿀 체 = 夫 + 夫 + 曰
       音 タイ(たい) · 訓 か(える)・か(わる)
       암구호(曰)를 주고받는 두 사내(夫夫) — 근무자가 바뀐다. 체인지(change)의 '체'
   (144) 潜 잠길 잠 = 氵 + 替
       音 セン(せん) · 訓 ひそ(む)・もぐ(る)
       일상이 바뀔(替) 만큼 큰물(氵) — 큰비에 삶의 터전이 잠긴다

   A: 夏休みに何をしますか。
      (なつやすみになにをしますか)
      여름휴가 때 뭐 해요?
   B: 海に潜りに行きます。その前に水着を買い替えます。
      (うみにもぐりにいきます。そのまえにみずぎをかいかえます)
      바다에 잠수하러 가요. 그 전에 수영복을 새로 사요.

   예문
   - 替(タイ・たい) : 交替で運転しましょう。
     (こうたいでうんてんしましょう) 교대로 운전해요.
   - 替(か)える : 空港でお金を円に替えました。
     (くうこうでおかねをえんにかえました) 공항에서 돈을 엔으로 바꿨어요.
   - 替(か)わる : 来月から担当が替わります。
     (らいげつからたんとうがかわります) 다음 달부터 담당이 바뀌어요.
   - 潜(セン・せん) : 潜水艦の中を見学しました。
     (せんすいかんのなかをけんがくしました) 잠수함 안을 견학했어요.
   - 潜(ひそ)む : 草むらに猫が潜んでいます。
     (くさむらにねこがひそんでいます) 풀숲에 고양이가 숨어 있어요.
   - 潜(もぐ)る : 海に潜って魚を見ました。
     (うみにもぐってさかなをみました) 바다에 잠수해서 물고기를 봤어요.

6. 旦(아침 단) 계열
   (145) 旦 아침 단 = 日 + 一
       音 タン(たん)・ダン(だん)
       땅(一) 위로 떠오르는 해(日) — 아침. 一旦(いったん) 멈춰
   (146) 早 이를 조 = 日 + 十
       音 ソウ(そう)・サッ(さっ) · 訓 はや(い)・はや(まる)・はや(める)
       저녁이 될 때까지 아직 해(日)가 많이(十) 남아 있다 — 이르다·빠르다
   (147) 草 풀 초 = 艹 + 早  (복습)
       音 ソウ(そう) · 訓 くさ
       풀(艹)은 빨리(早) 자라고 빨리 시든다
   (148) 但 다만 단 = 亻 + 旦
       訓 ただ(し)
       아침(旦)이 되면 어둠이 걷히고 실체가 드러난다 — 다만 사람(亻)은 드러난 것을 보기만 할 뿐
   (149) 担 멜 담 = 扌 + 旦
       音 タン(たん) · 訓 かつ(ぐ)・にな(う)
       아침(旦)이 되니 손(扌)으로 보따리에 물건을 담아 등에 메고 길을 나선다

   A: 明日は早く出発します。一旦、事務所に集まってください。
      (あしたははやくしゅっぱつします。いったん、じむしょにあつまってください)
      내일은 일찍 출발해요. 일단 사무실에 모여 주세요.
   B: わかりました。荷物は私が担ぎます。但し、重すぎるものは無理です。
      (わかりました。にもつはわたしがかつぎます。ただし、おもすぎるものはむりです)
      알겠어요. 짐은 제가 멜게요. 다만 너무 무거운 건 무리예요.

   예문
   - 旦(タン・たん) : 元旦に初日の出を見ました。
     (がんたんにはつひのでをみました) 설날 아침에 새해 첫 해돋이를 봤어요.
   - 旦(ダン・だん) : 旦那さんはお元気ですか。
     (だんなさんはおげんきですか) 남편분은 잘 지내세요?
   - 早(ソウ・そう) : 早朝に家を出ました。
     (そうちょうにいえをでました) 이른 아침에 집을 나섰어요.
   - 早(サッ・さっ) : 早速、始めましょう。
     (さっそく、はじめましょう) 바로 시작해요.
   - 早(はや)い : 父は毎朝起きるのが早いです。
     (ちちはまいあさおきるのがはやいです) 아버지는 매일 아침 일찍 일어나세요.
   - 早(はや)まる : 出発の時間が早まりました。
     (しゅっぱつのじかんがはやまりました) 출발 시간이 앞당겨졌어요.
   - 早(はや)める : 予定を一日早めました。
     (よていをいちにちはやめました) 일정을 하루 앞당겼어요.
   - 但(ただ)し : 入場は無料です。但し、予約が必要です。
     (にゅうじょうはむりょうです。ただし、よやくがひつようです) 입장은 무료예요. 단, 예약이 필요해요.
   - 担(タン・たん) : 私がこの仕事を担当します。
     (わたしがこのしごとをたんとうします) 제가 이 일을 담당해요.
   - 担(かつ)ぐ : 重い荷物を肩に担ぎました。
     (おもいにもつをかたにかつぎました) 무거운 짐을 어깨에 멨어요.
   - 担(にな)う : 若者が未来を担います。
     (わかものがみらいをにないます) 젊은이가 미래를 짊어져요.

포인트
   月 계열 이어서 : 明 = 日 + 月 / 服·脊·散의 月은 몸·고기(육달 월)
   明 읽기가 많다 : 説明(せつめい) · 明日(みょうにち) · 明るい · 明かり · 明らか · 夜が明ける · 明くる日 · 明かす
   明日 세 가지 읽기 : あした(일상) · あす · みょうにち(격식)
   散 4형제 : 散る(지다) · 散らす(흩뜨리다) · 散らかす(어지르다) · 散らかる(어질러지다)
   円 : 돈 단위 エン · 円い(まるい, 둥글다 — 丸い와 같은 소리)
   日 부품 셋 : 昌(日 둘) → 唱 / 晶(日 셋) / 是(日 + 疋)
   日 읽기 : 毎日(まいにち) · 本日(ほんじつ) · 日(ひ) · 三日(みっか)
   白 읽기 : 白紙(はくし) · 白夜(びゃくや) · 白(しろ) · 白髪(しらが) · 白い(しろい)
   是 가족 : 提·堤 テイ / 題 ダイ — 是非(ぜひ, 꼭)는 꼭 외우기
   提げる(さげる, 손에 들다)와 下げる(さげる, 내리다)는 소리가 같다
