오늘 읽은 문장: 歲月不待人 세월부대인 — 세월은 사람을 기다리지 않는다 (도연명 「잡시」)
여기서 待(기다릴 대)를 찾다가 寺 계열로 이어서 공부했다.

1. 至(이를 지) 계열
   (1) 屋 집 옥 = 尸 + 至
       音 オク(おく) · 訓 や
       몸(尸)이 이르는(至) 곳 — 가옥 전체
   (2) 握 쥘 악 = 扌 + 屋
       音 アク(あく) · 訓 にぎ(る)
       집(屋)만큼은 손(扌)에 꼭 쥐고 놓지 않는다
   (3) 窒 막힐 질 = 穴 + 至
       音 チツ(ちつ)
       동굴(穴)로 쏜 화살이 이르는(至) 곳은 벽 — 막힌다

   예문
   - 屋(や) : 駅の前に本屋があります。
     (えきのまえにほんやがあります) 역 앞에 서점이 있어요.
   - 屋(オク・おく) : 屋上からの景色がきれいです。
     (おくじょうからのけしきがきれいです) 옥상에서 보는 경치가 예뻐요.
   - 握(にぎ)る : 子どもの手をしっかり握りました。
     (こどものてをしっかりにぎりました) 아이 손을 꼭 잡았어요.
   - 握(アク・あく) : 新しい社長と握手しました。
     (あたらしいしゃちょうとあくしゅしました) 새 사장님과 악수했어요.
   - 窒(チツ・ちつ) : 煙で窒息しそうでした。
     (けむりでちっそくしそうでした) 연기 때문에 질식할 뻔했어요.

2. 寺(관청 시 · 절 사) 계열
   (1) 寺 절 사 = 土 + 寸
       音 ジ(じ) · 訓 てら
       땅(土)을 구획(寸)해 관리하던 관청 — 스님들이 머물며 절이 됨
   (2) 時 때 시 = 日 + 寺
       音 ジ(じ) · 訓 とき
       해(日)의 움직임에 따른 시간을 관청(寺)이 기록·관리
   (3) 待 기다릴 대 = 彳 + 寺
       音 タイ(たい) · 訓 ま(つ)
       관청(寺)에서 일을 보려고 길(彳)에 서서 기다린다
   (4) 特 특별할 특 = 牛 + 寺
       音 トク(とく)
       관청(寺)에서 관리하던 좋은 씨소(牛) — 특별하다
   (5) 等 무리 등 = ⺮ + 寺
       音 トウ(とう) · 訓 ひと(しい)
       관청(寺)의 책(⺮)은 등급별로 정리되어 있다
   (6) 持 가질 지 = 扌 + 寺
       音 ジ(じ) · 訓 も(つ)
       관청(寺)이 주요 정보를 손(扌)에 쥐고 있다
   (7) 侍 모실 시 = 亻 + 寺
       音 ジ(じ) · 訓 さむらい
       사람(亻)이 관청(寺)의 책임자를 모신다 — 일본에서는 사무라이
   (8) 詩 시 시 = 言 + 寺
       音 シ(し)
       절(寺)의 생활처럼 말(言)을 절제한 것

대화
   A: 待ち合わせは何時ですか。
      (まちあわせはなんじですか)
      약속 시간이 몇 시예요?
   B: 三時です。お寺の前で待っています。
      (さんじです。おてらのまえでまっています)
      3시예요. 절 앞에서 기다리고 있을게요.

   예문
   - 寺(てら) : 京都で古いお寺を見ました。
     (きょうとでふるいおてらをみました) 교토에서 오래된 절을 봤어요.
   - 寺(ジ・じ) : 有名な寺院を訪ねました。
     (ゆうめいなじいんをたずねました) 유명한 사원을 찾아갔어요.
   - 時(とき) : 子どもの時、よく川で遊びました。
     (こどものとき、よくかわであそびました) 어릴 때 자주 강에서 놀았어요.
   - 時(ジ・じ) : 三時に会いましょう。
     (さんじにあいましょう) 3시에 만나요.
   - 待(ま)つ : 駅で友だちを待っています。
     (えきでともだちをまっています) 역에서 친구를 기다리고 있어요.
   - 待(タイ・たい) : いい結果を期待しています。
     (いいけっかをきたいしています) 좋은 결과를 기대하고 있어요.
   - 特(トク・とく) : 今日は特別な日です。
     (きょうはとくべつなひです) 오늘은 특별한 날이에요.
   - 等(ひと)しい : 二つの線の長さは等しいです。
     (ふたつのせんのながさはひとしいです) 두 선의 길이는 같아요.
   - 等(トウ・とう) : くじで一等が当たりました。
     (くじでいっとうがあたりました) 추첨에서 1등이 당첨됐어요.
   - 持(も)つ : 傘を持っていますか。
     (かさをもっていますか) 우산 가지고 있어요?
   - 持(ジ・じ) : 健康を維持するために毎日歩きます。
     (けんこうをいじするためにまいにちあるきます) 건강을 유지하려고 매일 걸어요.
   - 侍(さむらい) : 昨日、侍の映画を見ました。
     (きのう、さむらいのえいがをみました) 어제 사무라이 영화를 봤어요.
   - 侍(ジ・じ) : 侍従 (じじゅう) 시종
   - 詩(シ・し) : 好きな詩を声に出して読みます。
     (すきなしをこえにだしてよみます) 좋아하는 시를 소리 내어 읽어요.

3. 而(말 이을 이, 기본자) 계열
   而 = 선비의 수염 — 입 아래로 이어진 수염 → '말을 잇다'
   (1) 耐 견딜 내 = 而 + 寸
       音 タイ(たい) · 訓 た(える)
       손(寸)으로 수염(而)을 뽑는 형벌을 견딘다
   (2) 端 끝 단 = 立 + 山 + 而
       音 タン(たん) · 訓 はし・は・はた
       노인(而)이 산(山)에 들어가 마지막 선(立) 곳 — 삶의 끝은 또 다른 시작
   (복습) 矢 화살 시
       音 シ(し) · 訓 や
       화살의 촉·대·오늬를 나타낸 글자

대화
   A: 疲れましたか。
      (つかれましたか)
      피곤해요?
   B: 少し。でも最後まで耐えます。
      (すこし。でもさいごまでたえます)
      조금요. 그래도 끝까지 견딜게요.

   예문
   - 而(ジ・じ) : 而立 (じりつ) 서른 살 — 『논어』 三十而立 (상용한자 아님)
   - 耐(た)える : 痛みに耐えて最後まで走りました。
     (いたみにたえてさいごまではしりました) 아픔을 견디며 끝까지 달렸어요.
   - 耐(タイ・たい) : この仕事には忍耐が必要です。
     (このしごとにはにんたいがひつようです) 이 일에는 인내가 필요해요.
   - 端(はし) : 道の端を歩いてください。
     (みちのはしをあるいてください) 길 가장자리로 걸어 주세요.
   - 端(は) : 半端 (はんぱ) 어중간함 (は → ぱ)
   - 端(はた) : 道端 (みちばた) 길가
   - 端(タン・たん) : 家に着いた途端、雨が降り出しました。
     (いえについたとたん、あめがふりだしました) 집에 도착하자마자 비가 내리기 시작했어요.
   - 矢(や) : 矢印の方へ進んでください。
     (やじるしのほうへすすんでください) 화살표 쪽으로 가 주세요.
   - 矢(シ・し) : 一矢を報いる (いっしをむくいる) 반격하다

포인트
   寺 ジ → 時·持·侍 ジ — 寺가 들어가니 소리도 그대로
   寺가 들어가도 소리가 바뀌는 글자 — 待 タイ · 特 トク · 等 トウ · 詩 シ
   至가 들어가도 소리는 제각각 — 屋 オク · 窒 チツ
   而 → 耐 タイ / 端 タン — 끝(端)은 또 다른 시작
