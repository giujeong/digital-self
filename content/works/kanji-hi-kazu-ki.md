46~54쪽. 旦(아침 단)에서 이어져 낮(昼)과 쓸개(胆). 햇빛이 아래위로 뻗는 기본자 亘(뻗칠 긍) — 담(垣), 밝히고(宣), 항상(恒). 해가 있다 없다 하는 易(쉬울 이)와 기본자 昜(볕 양) — 볕(陽), 틈(隙), 올리고(揚), 마당(場), 끓이고(湯), 다치고(傷), 창자(腸). 임신한 몸 身(몸 신) — 쏘고(射), 사과한다(謝). 그리고 숫자 一부터 万까지, 사이에 끊고(切) 둥근(丸). 마지막은 나무 木 — 삼나무(杉), 서로(相), 생각(想), 지키고(保), 수풀(林·森), 뿌리(本)와 몸(体), 끝(末)과 아직(未), 지운다(抹).

1. 旦(아침 단) 계열 — 45쪽에서 이어짐
   (150) 昼 낮 주 = 尺 + 旦
       音 チュウ(ちゅう) · 訓 ひる
       땅(一) 위에 떠 있는 해(日)를 자(尺)로 잴 수 있는 시간대
   (151) 胆 쓸개 담 = 月 + 旦
       音 タン(たん)
       사람의 몸(月)이 상쾌한 아침(旦)을 맞는다 — 쓸개는 소화효소 분비를 도와 속을 편하게 한다

   예문
   - 昼(チュウ・ちゅう) : 昼食は何にしますか。
     (ちゅうしょくはなににしますか) 점심은 뭘로 할까요?
   - 昼(ひる) : 昼休みに散歩します。
     (ひるやすみにさんぽします) 점심시간에 산책해요.
   - 胆(タン・たん) : 彼は大胆な人です。
     (かれはだいたんなひとです) 그는 대담한 사람이에요.

2. 亘(뻗칠 긍, 기본자) 계열
   亘 = 一 + 日 + 一 : 햇빛(日)이 아래(一)위(一)로 뻗친다. 구성요소로만 쓰임
   (152) 垣 담 원 = 土 + 亘
       訓 かき
       흙(土)이 아래위·좌우로 뻗어(亘) 나간 형태 — 土가 들어갔지만 일본에서는 나무 울타리
   (153) 宣 밝힐 선 = 宀 + 亘
       音 セン(せん)
       집안(宀)이 빛나면(亘) 그것이 곧 세상을 밝히는 것
   (154) 恒 항상 항 = 忄 + 亘
       音 コウ(こう)
       해가 항상 빛나듯(亘) 변치 않는 사람의 마음(忄)

   A: 庭の垣根を直しました。
      (にわのかきねをなおしました)
      마당 울타리를 고쳤어요.
   B: 恒例の大掃除ですね。
      (こうれいのおおそうじですね)
      늘 하는 대청소군요.

   예문
   - 垣(かき) : 石垣の上に猫がいます。
     (いしがきのうえにねこがいます) 돌담 위에 고양이가 있어요.
   - 宣(セン・せん) : 新製品の宣伝を始めました。
     (しんせいひんのせんでんをはじめました) 신제품 홍보를 시작했어요.
   - 恒(コウ・こう) : 毎朝の運動が恒例になりました。
     (まいあさのうんどうがこうれいになりました) 매일 아침 운동이 습관이 됐어요.

3. 昜(볕 양, 기본자) 계열 — 易도 함께
   昜 = 日 + 一 + 勿 : 해(日)가 땅(一) 위에 있으면 있고, 아래로 내려가면 없어지는(勿) 것이 볕. 구성요소로만 쓰임
   (155) 易 쉬울 이 = 日 + 勿
       音 エキ(えき)・イ(い) · 訓 やさ(しい)
       해(日)가 있다가 없다(勿) — 밤과 낮의 바뀜은 사람의 힘 없이 이루어지니 쉽다. 바꿀 역
   (156) 陽 볕 양 = 阝 + 昜
       音 ヨウ(よう)
       볕(昜)이 잘 드는 언덕(阝). 단독으로 쓰임
   (157) 隙 틈 극 = 阝 + 小 + 日 + 小
       音 ゲキ(げき) · 訓 すき
       볕이 잘 드는 언덕(阝)에서도 빛(日)이 작고(小) 작아지는(小) 틈
   (158) 揚 올릴 양 = 扌 + 昜
       音 ヨウ(よう) · 訓 あ(げる)・あ(がる)
       손(扌)으로 어둠 속 실체를 들어 올려 양지(昜)로 보낸다
   (159) 場 마당 장 = 土 + 昜
       音 ジョウ(じょう) · 訓 ば
       볕(昜)을 쬐기 위해 자주 나오는 땅(土)
   (160) 湯 끓일 탕 = 氵 + 昜
       音 トウ(とう) · 訓 ゆ
       물(氵)이 뜨거운 태양빛(昜)을 받으면 기화된다 — 끓는다
   (161) 傷 다칠 상 = 亻 + 𠂉 + 昜
       音 ショウ(しょう) · 訓 きず・いた(む)・いた(める)
       사람(亻)이 화살(𠂉, 矢의 간략형)을 맞아 다치니 몸에서 열(昜)이 난다
   (162) 腸 창자 장 = 月 + 昜
       音 チョウ(ちょう)
       몸(月) 중에서 따뜻해야(昜) 할 부위 — 속이 빈 창자는 쉽게 냉해져 병이 나기 쉽다

   A: 会場はどこですか。
      (かいじょうはどこですか)
      행사장은 어디예요?
   B: 陽の当たる広場です。寒いのでお湯を持って行きましょう。
      (ひのあたるひろばです。さむいのでおゆをもっていきましょう)
      볕이 드는 광장이에요. 추우니까 따뜻한 물을 가져가요.

   예문
   - 易(エキ・えき) : 貿易の仕事をしています。
     (ぼうえきのしごとをしています) 무역 일을 하고 있어요.
   - 易(イ・い) : この本は簡単で容易に読めます。
     (このほんはかんたんでよういによめます) 이 책은 간단해서 쉽게 읽혀요.
   - 易(やさ)しい : この問題は易しいです。
     (このもんだいはやさしいです) 이 문제는 쉬워요.
   - 陽(ヨウ・よう) : 太陽が東から昇ります。
     (たいようがひがしからのぼります) 태양이 동쪽에서 떠요.
   - 隙(ゲキ・げき) : 間隙を埋める必要があります。
     (かんげきをうめるひつようがあります) 간극을 메울 필요가 있어요.
   - 隙(すき) : ドアの隙間から風が入ります。
     (ドアのすきまからかぜがはいります) 문틈으로 바람이 들어와요.
   - 揚(ヨウ・よう) : 国旗を掲揚します。
     (こっきをけいようします) 국기를 게양해요.
   - 揚(あ)げる : 天ぷらを揚げました。
     (てんぷらをあげました) 튀김을 튀겼어요.
   - 揚(あ)がる : 花火が揚がりました。
     (はなびがあがりました) 불꽃이 올랐어요.
   - 場(ジョウ・じょう) : 駐車場に車を止めました。
     (ちゅうしゃじょうにくるまをとめました) 주차장에 차를 세웠어요.
   - 場(ば) : 会議の場所を教えてください。
     (かいぎのばしょをおしえてください) 회의 장소를 알려 주세요.
   - 湯(トウ・とう) : 銭湯に行きました。
     (せんとうにいきました) 대중목욕탕에 갔어요.
   - 湯(ゆ) : お湯を沸かします。
     (おゆをわかします) 물을 끓여요.
   - 傷(ショウ・しょう) : 事故で負傷しました。
     (じこでふしょうしました) 사고로 부상을 입었어요.
   - 傷(きず) : 指に傷ができました。
     (ゆびにきずができました) 손가락에 상처가 났어요.
   - 傷(いた)む : 夏は食べ物が傷みやすいです。
     (なつはたべものがいたみやすいです) 여름엔 음식이 상하기 쉬워요.
   - 傷(いた)める : 転んで足を傷めました。
     (ころんであしをいためました) 넘어져서 발을 다쳤어요.
   - 腸(チョウ・ちょう) : 腸の調子が悪いです。
     (ちょうのちょうしがわるいです) 장 상태가 안 좋아요.

4. 身(몸 신) 계열
   (163) 身 몸 신
       音 シン(しん) · 訓 み
       임신한 여자의 몸을 그린 글자 — 손으로 배를 받치고 있는 모습
   (164) 射 쏠 사 = 身 + 寸
       音 シャ(しゃ) · 訓 い(る)
       소전에는 활·사람·손이 있었으나 활이 빠지고 사람(身)과 손(寸)만 남았다
   (165) 謝 사과할 사 = 言 + 射
       音 シャ(しゃ) · 訓 あやま(る)
       잘못한 일이 있으면 활을 쏘듯이(射) 빨리 사과해라(言)

   A: 遅れてすみません。
      (おくれてすみません)
      늦어서 죄송해요.
   B: 謝らなくていいですよ。身体は大丈夫ですか。
      (あやまらなくていいですよ。からだはだいじょうぶですか)
      사과 안 해도 돼요. 몸은 괜찮아요?

   예문
   - 身(シン・しん) : 出身はどちらですか。
     (しゅっしんはどちらですか) 출신이 어디세요?
   - 身(み) : 身をもって学びました。
     (みをもってまなびました) 몸소 배웠어요.
   - 射(シャ・しゃ) : 注射を打ちました。
     (ちゅうしゃをうちました) 주사를 맞았어요.
   - 射(い)る : 弓で的を射ました。
     (ゆみでまとをいました) 활로 과녁을 쏘았어요.
   - 謝(シャ・しゃ) : 心から感謝します。
     (こころからかんしゃします) 진심으로 감사해요.
   - 謝(あやま)る : 友だちに謝りました。
     (ともだちにあやまりました) 친구에게 사과했어요.

5. 숫자 — 一부터 万까지
   (166) 一 한 일
       音 イチ(いち)・イツ(いつ) · 訓 ひと・ひと(つ)
       막대기 하나를 가로로 눕혀 하나
   (167) 二 두 이
       音 ニ(に) · 訓 ふた・ふた(つ)
       막대기 둘을 가로로 눕혀 둘
   (168) 三 석 삼
       音 サン(さん) · 訓 み・み(つ)・みっ(つ)
       막대기 셋을 가로로 눕혀 셋
   (169) 四 넉 사
       音 シ(し) · 訓 よ・よ(つ)・よっ(つ)・よん
       셋과 넷은 나란히 두면 구별이 어려워 사각형 囗 모양으로 차이를 드러냈다. 가운데 八은 '나누다'
   (170) 五 다섯 오
       音 ゴ(ご) · 訓 いつ・いつ(つ)
       높은 수(一)와 낮은 수(一)가 교차하는(X) 중간값 5
   (171) 六 여섯 육
       音 ロク(ろく) · 訓 む・む(つ)・むっ(つ)・むい
       지붕(亠)을 받치는 두 기둥(八)으로 집 — 한집에 사는 3대 6명
   (172) 七 일곱 칠
       音 シチ(しち) · 訓 なな・なな(つ)・なの
       칼로 나무를 자르는 모습 — '날카롭다'는 뜻도. 十과 구분하려고 아래를 구부림
   (173) 切 끊을 절 = 七 + 刀
       音 セツ(せつ)・サイ(さい) · 訓 き(る)・き(れる)
       날카로운(七) 칼(刀)로 자른다
   (174) 八 여덟 팔
       音 ハチ(はち) · 訓 や・や(つ)・やっ(つ)・よう
       잘린 두 동강으로 여덟. 부수로 쓰일 때는 '나누다' — 四·六·八에 들어감. 일본어 부수 모양은 ハ → 丷
   (175) 九 아홉 구
       音 キュウ(きゅう)・ク(く) · 訓 ここの・ここの(つ)
       손과 팔뚝, 팔 전체 — 손재주를 포함한 재능의 뛰어남. 사람이 도달할 수 있는 최고의 단계, 9단
   (176) 丸 둥글 환
       音 ガン(がん) · 訓 まる・まる(い)・まる(める)
       두 팔을 땅에 대고 몸을 둥글게 구부린 모습
   (177) 十 열 십
       音 ジュウ(じゅう)・ジッ(じっ) · 訓 とお・と
       막대기를 세워 10 — 이후 가로선을 더해 지금 모양
   (178) 百 일백 백 = 一 + 白
       音 ヒャク(ひゃく)
       나뭇가지(一)에 매달린 벌집(白) — 벌집 안에는 보통 100마리의 벌
   (179) 千 일천 천 = 亻 + 一
       音 セン(せん) · 訓 ち
       고대에는 사람(亻)의 다리에 줄(一)을 그어 '천 명'
   (180) 万 일만 만
       音 マン(まん)・バン(ばん)
       萬의 갑골문에는 전갈이 있었는데, 일본은 이를 줄인 万으로 '만'

   A: 全部でいくらですか。
      (ぜんぶでいくらですか)
      전부 얼마예요?
   B: 一万二千三百円です。切手は一枚百円です。
      (いちまんにせんさんびゃくえんです。きってはいちまいひゃくえんです)
      12,300엔이에요. 우표는 한 장에 100엔이고요.

   예문
   - 一(イチ・いち) : 一月に日本へ行きます。
     (いちがつににほんへいきます) 1월에 일본에 가요.
   - 一(イツ・いつ) : 統一テストを受けました。
     (とういつテストをうけました) 통일 시험을 봤어요.
   - 一(ひと) : 一人で来ました。
     (ひとりできました) 혼자 왔어요.
   - 一(ひと)つ : りんごを一つください。
     (りんごをひとつください) 사과 하나 주세요.
   - 二(ニ・に) : 二月は寒いです。
     (にがつはさむいです) 2월은 추워요.
   - 二(ふた) : 二人で食事しました。
     (ふたりでしょくじしました) 둘이서 식사했어요.
   - 二(ふた)つ : 卵を二つ使います。
     (たまごをふたつつかいます) 달걀 두 개를 써요.
   - 三(サン・さん) : 三月に卒業します。
     (さんがつにそつぎょうします) 3월에 졸업해요.
   - 三(み) : 三日月がきれいです。
     (みかづきがきれいです) 초승달이 예뻐요.
   - 三(み)つ : 三つ子が生まれました。
     (みつごがうまれました) 세쌍둥이가 태어났어요.
   - 三(みっ)つ : 質問が三つあります。
     (しつもんがみっつあります) 질문이 세 개 있어요.
   - 四(シ・し) : 四月から新学期です。
     (しがつからしんがっきです) 4월부터 새 학기예요.
   - 四(よ) : 四人家族です。
     (よにんかぞくです) 네 식구예요.
   - 四(よ)つ : 四つ角を右に曲がります。
     (よつかどをみぎにまがります) 사거리에서 오른쪽으로 돌아요.
   - 四(よっ)つ : みかんを四つ食べました。
     (みかんをよっつたべました) 귤을 네 개 먹었어요.
   - 四(よん) : 四時に会いましょう。
     (よじにあいましょう) 4시에 만나요.
   - 五(ゴ・ご) : 五月は気持ちがいいです。
     (ごがつはきもちがいいです) 5월은 기분이 좋아요.
   - 五(いつ) : 五日に出発します。
     (いつかにしゅっぱつします) 5일에 출발해요.
   - 五(いつ)つ : 五つ星のホテルです。
     (いつつぼしのホテルです) 5성급 호텔이에요.
   - 六(ロク・ろく) : 六時に起きます。
     (ろくじにおきます) 6시에 일어나요.
   - 六(む) : 六日は休みです。
     (むいかはやすみです) 6일은 쉬어요.
   - 六(む)つ : 六つ子の話を聞きました。
     (むつごのはなしをききました) 여섯쌍둥이 이야기를 들었어요.
   - 六(むっ)つ : パンを六つ買いました。
     (パンをむっつかいました) 빵을 여섯 개 샀어요.
   - 七(シチ・しち) : 七月は暑いです。
     (しちがつはあついです) 7월은 더워요.
   - 七(なな) : 七人で旅行しました。
     (ななにんでりょこうしました) 일곱이서 여행했어요.
   - 七(なな)つ : 七つの海を渡りました。
     (ななつのうみをわたりました) 일곱 바다를 건넜어요.
   - 七(なの) : 七日に帰ります。
     (なのかにかえります) 7일에 돌아가요.
   - 切(セツ・せつ) : 親切にしてもらいました。
     (しんせつにしてもらいました) 친절하게 대해 주셨어요.

6. 木(나무 목) 계열
   (181) 木 나무 목  (복습)
       音 モク(もく)・ボク(ぼく) · 訓 き・こ
       나무의 줄기(丨)와 가지(一), 뿌리(八)의 모양을 본뜬 글자
   (182) 杉 삼나무 삼 = 木 + 彡
       訓 すぎ
       나뭇잎이 가늘게(彡) 자라는 나무(木)
   (183) 相 서로 상 = 木 + 目
       音 ソウ(そう)・ショウ(しょう) · 訓 あい
       나무(木) 가지에도 눈(目)이 있어 서로의 상황을 살피며 공간을 나눈다
   (184) 想 생각 상 = 相 + 心
       音 ソウ(そう)・ソ(そ)
       서로(相)의 마음(心)을 생각한다
   (185) 保 지킬 보 = 亻 + 呆
       音 ホ(ほ) · 訓 たも(つ)
       아기가 나무(木)를 입(口)에 넣지 못하도록 사람(亻)이 지켜본다
   (186) 林 수풀 림 = 木 + 木
       音 リン(りん) · 訓 はやし
       나무(木)에 나무(木)를 더해 의미를 넓혔다
   (187) 森 수풀 삼 = 木 + 林
       音 シン(しん) · 訓 もり
       3개의 나무로 수풀
   (188) 本 근본 본 = 木 + 一
       音 ホン(ほん) · 訓 もと
       나무(木) 아래에 줄(一)을 그어 뿌리가 나무의 근본임을 나타낸다
   (189) 体 몸 체 = 亻 + 本
       音 タイ(たい)・テイ(てい) · 訓 からだ
       사람(亻)의 존재를 떠받치는 근본(本)은 몸
   (190) 末 끝 말 = 一 + 木
       音 マツ(まつ)・バツ(ばつ) · 訓 すえ
       나무(木) 위에 긴 줄(一)을 그어 끝까지 다 자랐음을 나타낸다
   (191) 未 아직 미 = 一 + 木  (복습)
       音 ミ(み)
       나무(木) 위에 짧은 줄(一)을 그어 아직 다 자라지 않았음을 나타낸다
   (192) 抹 지울 말 = 扌 + 末
       音 マツ(まつ)
       손(扌)이 끝(末)에 닿았다 — 손으로 해결했다, 문제를 다 지웠다
