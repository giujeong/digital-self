30~33쪽. 29쪽의 固(굳을 고)에 사람이 붙어 낱낱(個)이 되고, 칼 두 자루가 엇갈린 乂(벨 예)에서 베고(刈) 지도를 그리고(図) 흉한 상처(凶)가 나온다. 그 상처를 피하려고 머리털에 덮인 뇌(脳), 생각이 부딪치는 괴로움(悩), 몸으로 감싼 가슴(胸). 이어서 말(言)이 세고(計) 적고(記) 치고(討) 풀고(訳) 밝히고(証) 살핀다(診). 마지막은 눈(目) — 세운 눈, 내리깐 눈(臣), 감긴 눈(巨).

1. 固(굳을 고) 계열 — 29쪽에서 이어짐
   (72) 個 낱 개 = 亻 + 固
       音 コ(こ)
       사람(亻)의 성품도 오래되면 굳어져(固) 저마다 개성 있는 낱낱이 된다

   A: このりんご、一個いくらですか。
      (このりんご、いっこいくらですか)
      이 사과 한 개에 얼마예요?
   B: 一個百円です。個人のお客さんにも売りますよ。
      (いっこひゃくえんです。こじんのおきゃくさんにもうりますよ)
      한 개 100엔이에요. 개인 손님에게도 팔아요.

   예문
   - 個(コ・こ) : 個人の意見を聞かせてください。
     (こじんのいけんをきかせてください) 개인 의견을 들려주세요.

2. 乂(벨 예, 기본자) 계열
   乂 = 칼 두 자루가 엇갈린 모양 — 베다. 刈의 옛 글자
   (73) 刈 벨 예 = 乂 + 刂
       訓 か(る)
       날카로운 칼(刂)을 엇갈려(乂) 벤다
   (74) 図 그림 도 = 囗 + 乂 + 丶
       音 ズ(ず)・ト(と) · 訓 はか(る)
       칼로 서로 베는(乂) 두 무리(丶丶)가 부딪치는 변방의 지도(囗) — 지도에서 그림이 됐다
   (75) 凶 흉할 흉 = 凵 + 乂
       音 キョウ(きょう)
       베여(乂) 상처가 드러나니(凵) 흉하다. 囗는 감춰진 것, 凵는 드러난 것

   A: この地図を見てください。ここは昔、戦場でした。
      (このちずをみてください。ここはむかし、せんじょうでした)
      이 지도를 보세요. 여기는 옛날에 싸움터였어요.
   B: 今は田んぼですね。秋には稲を刈ります。
      (いまはたんぼですね。あきにはいねをかります)
      지금은 논이네요. 가을에는 벼를 베요.

   예문
   - 刈(か)る : 週末に庭の草を刈ります。
     (しゅうまつににわのくさをかります) 주말에 마당 풀을 베요.
   - 図(ズ・ず) : 駅までの地図を描きます。
     (えきまでのちずをかきます) 역까지 가는 지도를 그려요.
   - 図(ト・と) : 図書館で本を借ります。
     (としょかんでほんをかります) 도서관에서 책을 빌려요.
   - 図(はか)る : お客様の便宜を図ります。
     (おきゃくさまのべんぎをはかります) 손님의 편의를 도모해요.
   - 凶(キョウ・きょう) : 今年は雨が少なくて凶作でした。
     (ことしはあめがすくなくてきょうさくでした) 올해는 비가 적어서 흉작이었어요.

3. 彡(터럭 삼, 기본자) 계열
   彡 = 사람이나 짐승의 몸에 난 털 · 해가 비치는 모양. 脳·悩의 ⺍, 診의 㐱 안에 들어 있다

4. 凶(흉할 흉) 계열
   (76) 脳 뇌 뇌 = 月 + ⺍ + 凶
       音 ノウ(のう)
       흉한(凶) 상처가 나지 않도록 머리털(⺍)에 덮여 보호되는 몸(月)의 부위
   (77) 悩 번뇌할 뇌 = 忄 + ⺍ + 凶
       音 ノウ(のう) · 訓 なや(む)・なや(ます)
       마음(忄)이 바라는 것과 뇌(⺍+凶)에서 나온 생각이 부딪치니 괴롭다. 일본은 悩, 중국은 惱
   (78) 胸 가슴 흉 = 月 + 勹 + 凶
       音 キョウ(きょう) · 訓 むね・むな
       흉한(凶) 상처가 나지 않도록 몸(月)으로 감싸고(勹) 있는 부위

   A: 最近、何か悩んでいますか。
      (さいきん、なにかなやんでいますか)
      요즘 뭔가 고민 있어요?
   B: 試験のことで胸がいっぱいです。脳が疲れました。
      (しけんのことでむねがいっぱいです。のうがつかれました)
      시험 생각에 가슴이 꽉 찼어요. 머리가 지쳤어요.

   예문
   - 脳(ノウ・のう) : 寝ている間も脳は働いています。
     (ねているあいだものうははたらいています) 자는 동안에도 뇌는 일하고 있어요.
   - 悩(ノウ・のう) : 主人公の苦悩が伝わってきます。
     (しゅじんこうのくのうがつたわってきます) 주인공의 고뇌가 전해져요.
   - 悩(なや)む : 進路について悩んでいます。
     (しんろについてなやんでいます) 진로 때문에 고민하고 있어요.
   - 悩(なや)ます : 毎晩、騒音に悩まされています。
     (まいばん、そうおんになやまされています) 매일 밤 소음에 시달리고 있어요.
   - 胸(キョウ・きょう) : 健康診断で胸囲を測ります。
     (けんこうしんだんできょういをはかります) 건강검진에서 가슴둘레를 재요.
   - 胸(むね) : 走ったら胸が苦しくなりました。
     (はしったらむねがくるしくなりました) 달렸더니 가슴이 답답해졌어요.
   - 胸(むな) : 胸元にブローチを付けます。
     (むなもとにブローチをつけます) 가슴께에 브로치를 달아요.

5. 言(말씀 언) 계열
   (79) 言 말씀 언
       音 ゲン(げん)・ゴン(ごん) · 訓 い(う)・こと
       입(口)에서 나온 말은 파문처럼 언제나 퍼져 나간다
   (80) 計 셀 계 = 言 + 十
       音 ケイ(けい) · 訓 はか(る)・はか(らう)
       열(十)까지 말하며(言) 숫자를 센다 — 계산하다
   (81) 記 기록할 기 = 言 + 己
       音 キ(き) · 訓 しる(す)
       자기(己)의 생각이나 말(言)을 글로 기록한다 — 日記
   (82) 討 칠 토 = 言 + 寸
       音 トウ(とう) · 訓 う(つ)
       말(言)과 말이 이어지는 마디(寸), 곧 논리가 약한 곳을 친다
   (83) 訳 번역할 역 = 言 + 尺
       音 ヤク(やく) · 訓 わけ
       말(言)에 자(尺)를 대듯 따져 보는 이유와 사정 → 뜻을 밝히다 → 번역하다. 일본에서는 '이유·사정(わけ)'으로 자주 쓴다
   (84) 証 증거 증 = 言 + 正
       音 ショウ(しょう)
       말(言)로 올바름(正)을 증명한다
   (85) 診 진찰할 진 = 言 + 㐱
       音 シン(しん) · 訓 み(る)
       사람(人)의 머리숱(彡)처럼 많은 말(言)을 주고받으며 환자의 병을 진지하게 살핀다. 㐱 = 숱 많고 검을 진

   A: 昨日、病院で診てもらいました。
      (きのう、びょういんでみてもらいました)
      어제 병원에서 진찰받았어요.
   B: 先生は何と言いましたか。診断書は記入してもらいましたか。
      (せんせいはなんといいましたか。しんだんしょはきにゅうしてもらいましたか)
      선생님이 뭐라고 했어요? 진단서는 써 받았어요?

   예문
   - 言(ゲン・げん) : 会議で一人ずつ発言しました。
     (かいぎでひとりずつはつげんしました) 회의에서 한 명씩 발언했어요.
   - 言(ゴン・ごん) : 田中さんに伝言をお願いします。
     (たなかさんにでんごんをおねがいします) 다나카 씨에게 전언 부탁해요.
   - 言(い)う : もう一度言ってください。
     (もういちどいってください) 한 번 더 말해 주세요.
   - 言(こと) : 最後に一言お礼を言います。
     (さいごにひとことおれいをいいます) 마지막으로 한마디 감사 인사를 할게요.
   - 計(ケイ・けい) : 新しい時計を買いました。
     (あたらしいとけいをかいました) 새 시계를 샀어요.
   - 計(はか)る : ストップウォッチで時間を計ります。
     (ストップウォッチでじかんをはかります) 스톱워치로 시간을 재요.
   - 計(はか)らう : 先生がうまく計らってくれました。
     (せんせいがうまくはからってくれました) 선생님이 잘 처리해 주셨어요.
   - 記(キ・き) : 毎晩、日記を書きます。
     (まいばん、にっきをかきます) 매일 밤 일기를 써요.
   - 記(しる)す : ここに名前を記してください。
     (ここになまえをしるしてください) 여기에 이름을 적어 주세요.
   - 討(トウ・とう) : 来週までに検討します。
     (らいしゅうまでにけんとうします) 다음 주까지 검토할게요.
   - 討(う)つ : 主人公は父の仇を討ちました。
     (しゅじんこうはちちのかたきをうちました) 주인공은 아버지의 원수를 갚았어요.
   - 訳(ヤク・やく) : 英語の小説を翻訳します。
     (えいごのしょうせつをほんやくします) 영어 소설을 번역해요.
   - 訳(わけ) : 遅れた訳を話してください。
     (おくれたわけをはなしてください) 늦은 이유를 말해 주세요.
   - 証(ショウ・しょう) : 保証書をなくしてしまいました。
     (ほしょうしょをなくしてしまいました) 보증서를 잃어버렸어요.
   - 診(シン・しん) : 午後は診察がありません。
     (ごごはしんさつがありません) 오후에는 진찰이 없어요.
   - 診(み)る : 熱があるので医者に診てもらいます。
     (ねつがあるのでいしゃにみてもらいます) 열이 있어서 의사에게 진찰받아요.

6. 目(눈 목) 계열
   (86) 目 눈 목
       音 モク(もく)・ボク(ぼく) · 訓 め・ま
       눈을 세로로 세운 모양
   (87) 臣 신하 신
       音 シン(しん)・ジン(じん)
       눈을 내리깔고(눈이 조금 덮인 모양) 몸을 굽힌 신하의 모습
   (88) 巨 클 거
       音 キョ(きょ)
       완전히 감긴 눈 — 눈꺼풀이 세상을 덮을 만큼 크다. 巨大
   (89) 臨 임할 림 = 臣 + 𠂉 + 品
       音 リン(りん) · 訓 のぞ(む)
       세 그릇(品)에 음식을 담아 두고 몸을 굽힌(臣) 사람(𠂉)이 신께서 임하시길 바라며 제를 올린다
   (90) 距 떨어질 거 = 足 + 巨
       音 キョ(きょ)
       어른의 큰(巨) 발(足)로만 갈 수 있는 먼 거리

   A: 駅までの距離はどのくらいですか。
      (えきまでのきょりはどのくらいですか)
      역까지 거리는 얼마나 돼요?
   B: 歩いて十分です。あの巨大なビルが目印です。
      (あるいてじゅっぷんです。あのきょだいなビルがめじるしです)
      걸어서 10분이에요. 저 거대한 빌딩이 표시예요.

   예문
   - 目(モク・もく) : 旅行の目的は何ですか。
     (りょこうのもくてきはなんですか) 여행 목적이 뭐예요?
   - 目(ボク・ぼく) : 約束を守れなくて面目ないです。
     (やくそくをまもれなくてめんぼくないです) 약속을 못 지켜서 면목이 없어요.
   - 目(め) : パソコンで目が疲れました。
     (パソコンでめがつかれました) 컴퓨터 때문에 눈이 피곤해요.
   - 目(ま) : 事故を目の当たりにしました。
     (じこをまのあたりにしました) 사고를 눈앞에서 봤어요.
   - 臣(シン・しん) : 家臣たちが城を守りました。
     (かしんたちがしろをまもりました) 가신들이 성을 지켰어요.
   - 臣(ジン・じん) : 大臣が記者会見を開きました。
     (だいじんがきしゃかいけんをひらきました) 장관이 기자회견을 열었어요.
   - 巨(キョ・きょ) : 海の近くに巨大な橋があります。
     (うみのちかくにきょだいなはしがあります) 바다 근처에 거대한 다리가 있어요.
   - 臨(リン・りん) : 明日は臨時休業です。
     (あしたはりんじきゅうぎょうです) 내일은 임시 휴업이에요.
   - 臨(のぞ)む : 万全の準備で試合に臨みます。
     (ばんぜんのじゅんびでしあいにのぞみます) 만반의 준비로 경기에 임해요.
   - 距(キョ・きょ) : 家から会社まで距離があります。
     (いえからかいしゃまできょりがあります) 집에서 회사까지 거리가 있어요.

포인트
   個 = 亻 + 固 — 사람이 굳어 낱낱이 된다. 一個(いっこ), 個人(こじん). 일본 상용 읽기는 コ 하나
   乂 = 엇갈린 두 칼. 刈 か(る)는 훈독만, 図 ズ·ト·はかる, 凶 キョウ
   囗 vs 凵 : 사방이 막히면 감춰진 것(図), 위가 열리면 드러난 것(凶)
   凶 가족 : 脳·悩 = ⺍(머리털) + 凶, 胸 = 月 + 勹 + 凶. 脳·悩는 둘 다 ノウ, 胸만 キョウ(凶과 같은 소리)
   悩는 일본 자형, 중국·한국은 惱
   言 가족은 소리가 다 다르다 — 計 ケイ / 記 キ / 討 トウ / 訳 ヤク / 証 ショウ / 診 シン
   訳(わけ)는 일본에서 '번역'보다 '이유·사정'으로 더 자주 쓴다 — 言い訳(いいわけ, 변명)
   計る·測る·量る·図る는 모두 はかる — 計는 시간·수, 図는 계획·도모
   눈 셋 구별 : 目(세운 눈) / 臣(내리깐 눈, シン·ジン) / 巨(감긴 눈, キョ). 臨은 臣, 距는 巨에서 나온다
   반의어 : 凶 ↔ 吉 (흉 ↔ 길)
   읽기가 여러 개인 글자 — 図 ズ·ト·はかる / 悩 ノウ·なやむ·なやます / 胸 キョウ·むね·むな / 言 ゲン·ゴン·いう·こと / 計 ケイ·はかる·はからう / 記 キ·しるす / 討 トウ·うつ / 訳 ヤク·わけ / 診 シン·みる / 目 モク·ボク·め·ま / 臣 シン·ジン / 臨 リン·のぞむ
