책 맨 앞 13~18쪽을 다시 복습했다. 사람(人)과 큰 대(大)에서 시작해 亻·勹·巴·尸 같은 부수까지 이어지는 글자들.

1. 人(사람 인) 계열
   (1) 人 사람 인
       音 ジン(じん)・ニン(にん) · 訓 ひと
       길을 걸어가는 사람의 옆모습
   (2) 入 들 입
       音 ニュウ(にゅう) · 訓 い(る)・い(れる)・はい(る)
       사람이 문 안으로 다시 들어가는 모습 — 人과 뻗는 방향이 반대
   (3) 久 오랠 구 = ノ + 一 + 人
       音 キュウ(きゅう)・ク(く) · 訓 ひさ(しい)
       사람(人)에게 침(一)을 놓으니(ノ) 낫기까지 오래 걸린다
   (4) 囚 가둘 수 = 囗 + 人
       音 シュウ(しゅう)
       네모난 틀(囗)에 사람(人)을 가둔 죄수

   A: お久しぶりです。
      (おひさしぶりです)
      오랜만이에요.
   B: はい。大学に入学してから、ずっと忙しかったです。
      (はい。だいがくににゅうがくしてから、ずっといそがしかったです)
      네. 대학에 입학하고 나서 계속 바빴어요.

   예문
   - 人(ジン・じん) : 私は韓国人です。
     (わたしはかんこくじんです) 저는 한국 사람이에요.
   - 人(ニン・にん) : 三人で旅行に行きます。
     (さんにんでりょこうにいきます) 셋이서 여행을 가요.
   - 人(ひと) : あの人は私の先生です。
     (あのひとはわたしのせんせいです) 저 사람은 제 선생님이에요.
   - 入(ニュウ・にゅう) : 来年、大学に入学します。
     (らいねん、だいがくににゅうがくします) 내년에 대학에 입학해요.
   - 入(い)る : このかばんが気に入りました。
     (このかばんがきにいりました) 이 가방이 마음에 들었어요.
   - 入(い)れる : コーヒーに砂糖を入れます。
     (コーヒーにさとうをいれます) 커피에 설탕을 넣어요.
   - 入(はい)る : どうぞ、部屋に入ってください。
     (どうぞ、へやにはいってください) 어서 방에 들어오세요.
   - 久(キュウ・きゅう) : この思い出は永久に忘れません。
     (このおもいではえいきゅうにわすれません) 이 추억은 영원히 잊지 않을 거예요.
   - 久(ク・く) : 久遠 (くおん) 영원 (드물게 씀)
   - 久(ひさ)しい : お久しぶりですね。
     (おひさしぶりですね) 오랜만이네요.
   - 囚(シュウ・しゅう) : 映画で囚人が逃げました。
     (えいがでしゅうじんがにげました) 영화에서 죄수가 도망쳤어요.

2. 大(큰 대) 계열
   (1) 大 큰 대
       音 ダイ(だい)・タイ(たい) · 訓 おお・おお(きい)・おお(いに)
       사람이 두 팔을 벌리니 커 보인다 — 다 큰 사람(성인)
   (2) 因 인할 인 = 囗 + 大
       音 イン(いん) · 訓 よ(る)
       다 큰 사람(大)이 자리(囗)에 누워만 있는 데는 이유가 있다
   (3) 太 클 태 = 大 + 丶
       音 タイ(たい)・タ(た) · 訓 ふと(い)・ふと(る)
       큰(大) 우주도 태초에는 작은 점(丶) 하나였다
   (4) 犬 개 견 = 大 + 丶 (변으로 쓰면 犭)
       音 ケン(けん) · 訓 いぬ
       남의 물건에 침(丶)을 흘리는 사람(大)은 개와 같다
   (5) 夫 지아비 부 = 一 + 大
       音 フ(ふ)・フウ(ふう) · 訓 おっと
       성인(大) 머리에 비녀(一)를 꽂은 사내 — 누군가의 남편
   (6) 天 하늘 천 = 一 + 大
       音 テン(てん) · 訓 あめ・あま
       팔 벌린 사람(大) 머리 위로 펼쳐진(一) 하늘
   (7) 失 잃을 실 = 𠂉 + 大
       音 シツ(しつ) · 訓 うしな(う)
       어른(大)이 아이(𠂉)를 목말 태우며 자기 것을 많이 잃는다

   A: 明日の天気はどうですか。
      (あしたのてんきはどうですか)
      내일 날씨 어때요?
   B: 晴れです。夫と犬の散歩に行きます。
      (はれです。おっとといぬのさんぽにいきます)
      맑아요. 남편이랑 개 산책 가요.

   예문
   - 大(ダイ・だい) : 大学で日本語を勉強しています。
     (だいがくでにほんごをべんきょうしています) 대학에서 일본어를 공부하고 있어요.
   - 大(タイ・たい) : 家族は大切です。
     (かぞくはたいせつです) 가족은 소중해요.
   - 大(おお) : 昨日は大雨でした。
     (きのうはおおあめでした) 어제는 큰비가 왔어요.
   - 大(おお)きい : 庭に大きい木があります。
     (にわにおおきいきがあります) 마당에 큰 나무가 있어요.
   - 大(おお)いに : 週末は大いに楽しみました。
     (しゅうまつはおおいにたのしみました) 주말에 실컷 즐겼어요.
   - 因(イン・いん) : 事故の原因を調べています。
     (じこのげんいんをしらべています) 사고 원인을 조사하고 있어요.
   - 因(よ)る : 病気に因る欠席です。
     (びょうきによるけっせきです) 병으로 인한 결석이에요. (보통 かな로 씀)
   - 太(タイ・たい) : 太陽がまぶしいです。
     (たいようがまぶしいです) 해가 눈부셔요.
   - 太(タ・た) : 丸太で小さい橋を作りました。
     (まるたでちいさいはしをつくりました) 통나무로 작은 다리를 만들었어요.
   - 太(ふと)い : 太いペンで名前を書きます。
     (ふといペンでなまえをかきます) 굵은 펜으로 이름을 써요.
   - 太(ふと)る : 最近、少し太りました。
     (さいきん、すこしふとりました) 요즘 살이 좀 쪘어요.
   - 犬(ケン・けん) : 毎朝、愛犬と散歩します。
     (まいあさ、あいけんとさんぽします) 매일 아침 반려견과 산책해요.
   - 犬(いぬ) : 小さい犬を飼っています。
     (ちいさいいぬをかっています) 작은 개를 키워요.
   - 夫(フ・ふ) : 農夫が畑で働いています。
     (のうふがはたけではたらいています) 농부가 밭에서 일하고 있어요.
   - 夫(フウ・ふう) : 夫婦で旅行に行きました。
     (ふうふでりょこうにいきました) 부부가 함께 여행을 갔어요.
   - 夫(おっと) : 夫は会社員です。
     (おっとはかいしゃいんです) 남편은 회사원이에요.
   - 天(テン・てん) : 明日の天気はどうですか。
     (あしたのてんきはどうですか) 내일 날씨 어때요?
   - 天(あま) : 夏の夜、天の川が見えました。
     (なつのよる、あまのがわがみえました) 여름밤에 은하수가 보였어요.
   - 失(シツ・しつ) : お先に失礼します。
     (おさきにしつれいします) 먼저 실례하겠습니다.
   - 失(うしな)う : 試合に負けて自信を失いました。
     (しあいにまけてじしんをうしないました) 시합에 져서 자신감을 잃었어요.

3. 亻(사람 인 변, 기본자) 계열
   亻 = 人이 글자 왼쪽에 올 때의 모양 (머리에 올 때는 𠂉)
   (1) 仙 신선 선 = 亻 + 山
       音 セン(せん)
       사람(亻)이 산(山)에서 도를 닦으면 신선이 된다
   (2) 仁 어질 인 = 亻 + 二
       音 ジン(じん)・ニ(に)
       사람(亻)이 자신을 두 번째(二)로 여길 때 어질다
   (3) 信 믿을 신 = 亻 + 言
       音 シン(しん)
       사람(亻)의 말(言)에 믿음이 생긴다
   (4) 立 설 립
       音 リツ(りつ)・リュウ(りゅう) · 訓 た(つ)・た(てる)
       땅 위에 서 있는 사람의 모습
   (5) 位 자리 위 = 亻 + 立
       音 イ(い) · 訓 くらい
       사람(亻)이 서(立) 있는 곳이 그 사람의 자리

   A: あの人の話を信じますか。
      (あのひとのはなしをしんじますか)
      저 사람 말을 믿어요?
   B: はい。いつも約束を守る立派な人ですから。
      (はい。いつもやくそくをまもるりっぱなひとですから)
      네. 늘 약속을 지키는 훌륭한 사람이니까요.

   예문
   - 仙(セン・せん) : 山の中で仙人のように暮らしています。
     (やまのなかでせんにんのようにくらしています) 산속에서 신선처럼 살고 있어요.
   - 仁(ジン・じん) : 仁術 (じんじゅつ) 인술 — 사람을 살리는 의술
   - 仁(ニ・に) : お寺の門に仁王が立っています。
     (おてらのもんににおうがたっています) 절 문에 인왕상이 서 있어요.
   - 信(シン・しん) : 私は彼を信じています。
     (わたしはかれをしんじています) 저는 그를 믿고 있어요.
   - 立(リツ・りつ) : 週末に国立公園へ行きます。
     (しゅうまつにこくりつこうえんへいきます) 주말에 국립공원에 가요.
   - 立(リュウ・りゅう) : 建立 (こんりゅう) 건립 — 절·탑을 세움
   - 立(た)つ : 駅の前に立っています。
     (えきのまえにたっています) 역 앞에 서 있어요.
   - 立(た)てる : 旅行の計画を立てましょう。
     (りょこうのけいかくをたてましょう) 여행 계획을 세웁시다.
   - 位(イ・い) : マラソンで一位になりました。
     (マラソンでいちいになりました) 마라톤에서 1등을 했어요.
   - 位(くらい) : 位の高い人に会いました。
     (くらいのたかいひとにあいました) 지위가 높은 사람을 만났어요.

4. 勹(쌀 포, 기본자) 계열
   勹 = 사람이 몸을 구부려 무언가를 감싸고 있는 모습 — 단독으로는 쓰지 않고 부수로만 씀
   (1) 己 몸 기
       音 コ(こ)・キ(き) · 訓 おのれ
       몸을 구부린 태아의 모습 — 나라는 존재는 몸에서 시작한다
   (2) 包 쌀 포 = 勹 + 己
       音 ホウ(ほう) · 訓 つつ(む)
       어머니의 몸(勹)이 태아(己)를 포근히 감싸고 있다
   (3) 句 글 구 = 勹 + 口
       音 ク(く)
       입(口)에서 나온 좋은 말을 싸서(勹) 글로 담아 둔다

   A: 自己紹介をお願いします。
      (じこしょうかいをおねがいします)
      자기소개 부탁해요.
   B: はい。料理が好きで、包丁を使うのが得意です。
      (はい。りょうりがすきで、ほうちょうをつかうのがとくいです)
      네. 요리를 좋아하고 칼 쓰는 게 특기예요.

   예문
   - 己(コ・こ) : 自己紹介をします。
     (じこしょうかいをします) 자기소개를 하겠습니다.
   - 己(キ・き) : 知己 (ちき) 지기 — 나를 알아주는 벗
   - 己(おのれ) : 己を知ることが大切です。
     (おのれをしることがたいせつです) 자신을 아는 것이 중요해요.
   - 包(ホウ・ほう) : 包丁で野菜を切ります。
     (ほうちょうでやさいをきります) 식칼로 채소를 썰어요.
   - 包(つつ)む : プレゼントをきれいな紙で包みました。
     (プレゼントをきれいなかみでつつみました) 선물을 예쁜 종이로 쌌어요.
   - 句(ク・く) : 初めて俳句を作ってみました。
     (はじめてはいくをつくってみました) 처음으로 하이쿠를 지어 봤어요.

5. 巴(꼬리 파, 기본자) 계열
   巴 = 무언가를 잡으려고 손을 내미는 모습 (꼬리와는 관계없음)
   (1) 色 빛 색 = ⺈ + 巴
       音 ショク(しょく)・シキ(しき) · 訓 いろ
       몸을 감싸(⺈) 붙잡으면(巴) 감정이 올라 얼굴빛이 변한다
   (2) 把 잡을 파 = 扌 + 巴
       音 ハ(は)
       손(扌)을 내밀어 힘껏 잡는다(巴)
   (3) 肥 살찔 비 = 月 + 巴
       音 ヒ(ひ) · 訓 こ(える)・こえ・こ(やす)・こ(やし)
       고기(月)만 보면 손을 내밀어 잡으니(巴) 살이 찐다

   A: このお店の野菜は色がきれいですね。
      (このおみせのやさいはいろがきれいですね)
      이 가게 채소는 색이 예쁘네요.
   B: はい。土をよく肥やして育てたそうです。
      (はい。つちをよくこやしてそだてたそうです)
      네. 흙을 잘 기름지게 해서 키웠대요.

   예문
   - 色(ショク・しょく) : この町の特色は温泉です。
     (このまちのとくしょくはおんせんです) 이 동네의 특색은 온천이에요.
   - 色(シキ・しき) : 色彩がとても豊かな絵です。
     (しきさいがとてもゆたかなえです) 색채가 아주 풍부한 그림이에요.
   - 色(いろ) : 好きな色は何ですか。
     (すきないろはなんですか) 좋아하는 색이 뭐예요?
   - 把(ハ・は) : まず状況を把握しましょう。
     (まずじょうきょうをはあくしましょう) 먼저 상황을 파악합시다.
   - 肥(ヒ・ひ) : 畑に肥料をまきました。
     (はたけにひりょうをまきました) 밭에 비료를 뿌렸어요.
   - 肥(こ)える : この土地はよく肥えています。
     (このとちはよくこえています) 이 땅은 아주 비옥해요.
   - 肥(こえ) : 肥 (こえ) 거름 (단어로 씀)
   - 肥(こ)やす : 落ち葉で土を肥やします。
     (おちばでつちをこやします) 낙엽으로 흙을 기름지게 해요.
   - 肥(こ)やし : 失敗も人生の肥やしです。
     (しっぱいもじんせいのこやしです) 실패도 인생의 거름이에요.

6. 尸(주검 시, 기본자) 계열
   尸 = 누워 있는 주검의 모습 — 살아 있는 사람(몸)을 뜻하기도 한다
   (1) 尺 자 척 = 尸 + 丶
       音 シャク(しゃく)
       주검(尸)을 담을 관의 길이를 자로 잰다(丶)
   (2) 尽 다할 진 = 尺 + ⺀
       音 ジン(じん) · 訓 つ(くす)・つ(きる)・つ(かす)
       자(尺)로 잰 관 속 주검이 얼음(⺀)처럼 식었다 — 삶이 다했다
   (3) 沢 못 택 = 氵 + 尺
       音 タク(たく) · 訓 さわ
       바다는 못 재도 연못 물(氵)은 자(尺)로 잴 수 있다 — 작은 못

   A: 週末は何をしましたか。
      (しゅうまつはなにをしましたか)
      주말에 뭐 했어요?
   B: 山の沢で友だちと休みました。話が尽きませんでした。
      (やまのさわでともだちとやすみました。はなしがつきませんでした)
      산 계곡에서 친구랑 쉬었어요. 이야기가 끝이 없었어요.

   예문
   - 尺(シャク・しゃく) : 地図の縮尺を確認してください。
     (ちずのしゅくしゃくをかくにんしてください) 지도의 축척을 확인해 주세요.
   - 尽(ジン・じん) : 皆さんのご尽力に感謝します。
     (みなさんのごじんりょくにかんしゃします) 여러분의 노고에 감사드려요.
   - 尽(つ)くす : 最後まで最善を尽くします。
     (さいごまでさいぜんをつくします) 끝까지 최선을 다하겠습니다.
   - 尽(つ)きる : 友だちと話が尽きません。
     (ともだちとはなしがつきません) 친구와 이야기가 끝이 없어요.
   - 尽(つ)かす : 愛想を尽かす (あいそをつかす) 정나미가 떨어지다
   - 沢(タク・たく) : この机は光沢があってきれいです。
     (このつくえはこうたくがあってきれいです) 이 책상은 광택이 나서 예뻐요.
   - 沢(さわ) : 沢の水がとても冷たいです。
     (さわのみずがとてもつめたいです) 계곡물이 아주 차가워요.

7. 卩(병부 절, 기본자) 계열 — 다음 쪽 글자로 이어짐
   卩 = 무릎 꿇은 사람의 모습 — 죄인이나 굽힌 몸 (㔾은 卩의 변형, 뜻이 같다)

포인트
   人 사람(걸어가는 옆모습) ↔ 入 들어감 — 모양이 거울처럼 반대
   囚 シュウ ↔ 因 イン — 囗 안에 人이면 갇힌 죄수, 大면 누워 있는 이유
   大 → 太 → 犬 : 점(丶)이 아래면 太(클 태), 오른쪽 위면 犬(개 견)
   夫 ↔ 天 : 세로획이 위로 뚫고 나오면 夫(비녀 꽂은 남편), 一이 머리 위에 얹히면 天(하늘)
   亻 = 人이 왼쪽에 올 때 · 𠂉 = 머리에 올 때 (失)
   亻 + 立 = 位 — 서 있는 곳이 자리
   勹 + 己 = 包 — 감싸면 포(包), 包丁 ほうちょう는 식칼
   勹 + 口 = 句 ク — 감싸는 것이 몸이면 包, 말이면 句
   巴가 들어간 글자 — 色 ショク·シキ / 把 ハ / 肥 ヒ (모두 손을 내밀어 잡는 巴)
   月이 왼쪽이나 아래에 오면 육달 월(고기) — 肥
   尸 → 尺 シャク → 尽 ジン · 沢 タク — 자(尺)로 재는 글자들
   읽기가 여러 개인 글자 — 人 ジン·ニン·ひと / 入 ニュウ·いる·いれる·はいる / 久 キュウ·ク·ひさしい / 大 ダイ·タイ·おお·おおきい·おおいに / 太 タイ·タ·ふとい·ふとる / 夫 フ·フウ·おっと / 天 テン·あめ·あま / 立 リツ·リュウ·たつ·たてる / 己 コ·キ·おのれ / 色 ショク·シキ·いろ / 肥 ヒ·こえる·こえ·こやす·こやし / 尽 ジン·つくす·つきる·つかす / 沢 タク·さわ
