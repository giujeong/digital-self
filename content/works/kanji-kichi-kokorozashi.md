1. 吉(길할 길) 계열
   (1) 吉 길할 길 = 士 + 口 (여기서는 모양자)
       音 キチ(きち)・キツ(きつ)
       뚜껑(士)과 그릇(口) — 뚜껑을 닫았으니 마무리가 잘 됐다 → 길하다
   (2) 詰 물을 힐 = 言 + 吉
       音 キツ(きつ) · 訓 つ(める)・つ(まる)・つ(む)
       마무리가 잘 됐는지(吉) 묻는다(言) / 빈틈없이 채우다

2. 士(선비 사) 계열
   (3) 声 소리 성 = 士 + 尸(석경 모양)
       音 セイ(せい)・ショウ(しょう) · 訓 こえ・こわ
       선비(士)가 석경을 쳐서 소리를 낸다
   (4) 志 뜻 지 = 士 + 心
       音 シ(し) · 訓 こころざ(す)・こころざし
       선비(士)의 마음(心) 속에 지닌 뜻
   (5) 誌 기록할 지 = 言 + 志
       音 シ(し)
       말(言)의 뜻(志)을 바르게 지키기 위해 기록한다

   A: この雑誌、声優の特集ですね。
      (このざっし、せいゆうのとくしゅうですね)
      이 잡지, 성우 특집이네요.
   B: はい、私の志は声優になることなんです。
      (はい、わたしのこころざしはせいゆうになることなんです)
      네, 제 꿈은 성우가 되는 거예요.

   예문
   - 吉(キチ・きち) : おみくじで大吉が出ました。
     (おみくじでだいきちがでました) 오미쿠지에서 대길이 나왔어요.
   - 吉(キツ・きつ) : 不吉な夢を見ました。
     (ふきつなゆめをみました) 불길한 꿈을 꿨어요.
   - 詰(つ)める : かばんに荷物を詰めます。
     (かばんににもつをつめます) 가방에 짐을 채워 넣어요.
   - 詰(つ)まる : 風邪で鼻が詰まっています。
     (かぜではながつまっています) 감기로 코가 막혔어요.
   - 詰(つ)む : この将棋はもう詰んでいます。
     (このしょうぎはもうつんでいます) 이 장기는 이미 외통수예요.
   - 詰(キツ・きつ) : 遅刻の理由を詰問されました。
     (ちこくのりゆうをきつもんされました) 지각한 이유를 추궁당했어요.
   - 声(こえ) : もう少し大きい声で話してください。
     (もうすこしおおきいこえではなしてください) 조금 더 큰 목소리로 말해 주세요.
   - 声(こわ) : 声色を変えて話しました。
     (こわいろをかえてはなしました) 목소리를 바꿔서 말했어요.
   - 声(セイ・せい) : 彼女は有名な声優です。
     (かのじょはゆうめいなせいゆうです) 그녀는 유명한 성우예요.
   - 声(ショウ・しょう) : 大音声 (だいおんじょう) 크게 외치는 소리 (しょう → じょう로 탁음화)
   - 志(こころざ)す : 弟は医者を志しています。
     (おとうとはいしゃをこころざしています) 남동생은 의사를 지망하고 있어요.
   - 志(こころざし) : 高い志を持って働きます。
     (たかいこころざしをもってはたらきます) 높은 뜻을 품고 일해요.
   - 志(シ・し) : 第一志望の大学に合格しました。
     (だいいちしぼうのだいがくにごうかくしました) 1지망 대학에 합격했어요.
   - 誌(シ・し) : 駅で雑誌を買いました。
     (えきでざっしをかいました) 역에서 잡지를 샀어요.

포인트
   志 シ → 誌 シ — 志가 들어가니 소리도 그대로
   吉 キチ·キツ → 詰 キツ — 吉의 소리를 이어받는다
   士가 吉에서는 '뚜껑' 모양, 声·志에서는 '선비' — 같은 모양도 글자마다 역할이 다르다
