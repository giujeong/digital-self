19~21쪽. 앞 쪽에서 이어진 卩(병부 절)과 大(큰 대)를 마무리하고, 손(手·扌)에서 오른손(ナ)·왼손, 또 우(又)까지 이어진다.

1. 卩(병부 절, 기본자) 계열 — 18쪽에서 이어짐
   卩 = 무릎 꿇은 사람의 모습 — 죄인이나 굽힌 몸 (㔾은 卩의 변형, 뜻이 같다)
   (26) 犯 범할 범 = 犭 + 卩
       音 ハン(はん) · 訓 おか(す)
       짐승(犭) 같은 짓을 저지른 죄인(卩)이 무릎을 꿇고 있다 — 죄를 범했다
   (27) 氾 넘칠 범 = 氵 + 卩
       音 ハン(はん)
       물(氵)로 죄인(卩)들을 심판하시어 세상에 물이 넘쳤다 — 범람

   A: 昨日、川が氾濫したそうですね。
      (きのう、かわがはんらんしたそうですね)
      어제 강이 범람했다면서요.
   B: はい。でも、法を犯して逃げた人はいませんでした。
      (はい。でも、ほうをおかしてにげたひとはいませんでした)
      네. 그래도 법을 어기고 도망친 사람은 없었어요.

   예문
   - 犯(ハン・はん) : 警察が犯罪を防ぎます。
     (けいさつがはんざいをふせぎます) 경찰이 범죄를 막아요.
   - 犯(おか)す : 法を犯してはいけません。
     (ほうをおかしてはいけません) 법을 어기면 안 돼요.
   - 氾(ハン・はん) : 大雨で川が氾濫しました。
     (おおあめでかわがはんらんしました) 큰비로 강이 범람했어요.

2. 大(큰 대) 계열 — 16쪽에서 이어짐
   (28) 爽 시원할 상 = 大 + 㸚
       音 ソウ(そう) · 訓 さわ(やか)
       팔 벌린 사람(大)의 옆구리로 바람개비(㸚)가 씽씽 돌아가니 상당히 시원하다
   (29) 器 그릇 기 = 㗊 + 大
       音 キ(き) · 訓 うつわ
       가운데 있는 사람(大) 주변으로 그릇들(㗊)이 놓여 있다

   A: 今日は爽やかな天気ですね。
      (きょうはさわやかなてんきですね)
      오늘 날씨가 상쾌하네요.
   B: ええ。公園で楽器の練習をしましょう。
      (ええ。こうえんでがっきのれんしゅうをしましょう)
      네. 공원에서 악기 연습해요.

   예문
   - 爽(ソウ・そう) : 朝のシャワーは爽快です。
     (あさのシャワーはそうかいです) 아침 샤워는 상쾌해요.
   - 爽(さわ)やか : 今日は爽やかな風が吹いています。
     (きょうはさわやかなかぜがふいています) 오늘은 상쾌한 바람이 불어요.
   - 器(キ・き) : ピアノは好きな楽器です。
     (ピアノはすきながっきです) 피아노는 좋아하는 악기예요.
   - 器(うつわ) : 料理をきれいな器に盛ります。
     (りょうりをきれいなうつわにもります) 요리를 예쁜 그릇에 담아요.

3. 手(손 수) 계열
   (30) 手 손 수 (변으로 쓰면 扌)
       音 シュ(しゅ) · 訓 て・た
       사람의 손을 본뜬 글자 — 긴 가운뎃손가락은 꺾인 형태로 표현했다. 扌은 手를 간략히 나타낸 부수
   (31) 扶 도울 부 = 扌 + 夫
       音 フ(ふ)
       손(扌)을 보태서 지아비(夫)를 부지런히 돕는다
   (32) 択 고를 택 = 扌 + 尺
       音 タク(たく)
       손(扌)에 자(尺)를 들고 크기에 맞는 물건을 고른다 — 택한다
   (33) 拉 끌 랍 = 扌 + 立
       音 ラ(ら)
       서 있는 사람(立)을 손(扌)으로 끌어당긴다 — 납치

   A: 好きな科目を選択しましたか。
      (すきなかもくをせんたくしましたか)
      좋아하는 과목을 선택했어요?
   B: はい。手を挙げて先生に伝えました。
      (はい。てをあげてせんせいにつたえました)
      네. 손을 들어서 선생님께 말했어요.

   예문
   - 手(シュ・しゅ) : 彼はサッカーの選手です。
     (かれはサッカーのせんしゅです) 그는 축구 선수예요.
   - 手(て) : 食べる前に手を洗ってください。
     (たべるまえにてをあらってください) 먹기 전에 손을 씻으세요.
   - 手(た) : 馬の手綱を引きます。
     (うまのたづなをひきます) 말의 고삐를 당겨요.
   - 扶(フ・ふ) : 両親を扶養しています。
     (りょうしんをふようしています) 부모님을 부양하고 있어요.
   - 択(タク・たく) : 好きな科目を選択します。
     (すきなかもくをせんたくします) 좋아하는 과목을 선택해요.
   - 拉(ラ・ら) : 拉致問題はまだ解決していません。
     (らちもんだいはまだかいけつしていません) 납치 문제는 아직 해결되지 않았어요.

4. 오른손과 왼손 — 右 左 佐 存 在
   (34) 右 오른 우 = ナ + 口
       音 ウ(う)・ユウ(ゆう) · 訓 みぎ
       5개(扌)의 손가락을 더욱 간단히 줄여 3개(ナ)로 표현. 밥 먹을(口) 때 사용하는 손(ナ)은 오른손
   (35) 左 왼 좌 = ナ + 工
       音 サ(さ) · 訓 ひだり
       장인(工)은 왼손(ナ)마저도 잘 사용한다 — 장인인지 알려면 그의 왼손을 봐라
   (36) 佐 도울 좌 = 亻 + 左
       音 サ(さ)
       사람(亻)의 서툰(左) 부분을 도와 보좌한다
   (37) 存 있을 존 = ナ + 丨 + 子
       音 ソン(そん)・ゾン(ぞん)
       손(ナ)으로 말뚝(丨)을 박아 아이(子)가 태어났음을 나타냄 — 신생아가 있는 zone(존)
   (38) 在 있을 재 = ナ + 丨 + 土
       音 ザイ(ざい) · 訓 あ(る)
       손(ナ)으로 말뚝(丨)을 박아 자신의 땅(土) 경계를 나타냄 — 땅은 가장 큰 재산

   A: すみません、駅はどこですか。
      (すみません、えきはどこですか)
      실례합니다, 역이 어디예요?
   B: 次の角を右に曲がって、左の道を行ってください。
      (つぎのかどをみぎにまがって、ひだりのみちをいってください)
      다음 모퉁이에서 오른쪽으로 돌아서 왼쪽 길로 가세요.

   예문
   - 右(ウ・う) : 次の角を右折してください。
     (つぎのかどをうせつしてください) 다음 모퉁이에서 우회전하세요.
   - 右(ユウ・ゆう) : 左右をよく見て渡ります。
     (さゆうをよくみてわたります) 좌우를 잘 보고 건너요.
   - 右(みぎ) : 右に曲がってください。
     (みぎにまがってください) 오른쪽으로 도세요.
   - 左(サ・さ) : 交差点で左折します。
     (こうさてんでさせつします) 교차로에서 좌회전해요.
   - 左(ひだり) : 左の道を行きます。
     (ひだりのみちをいきます) 왼쪽 길로 가요.
   - 佐(サ・さ) : 社長を補佐しています。
     (しゃちょうをほさしています) 사장님을 보좌하고 있어요.
   - 存(ソン・そん) : ファイルを保存します。
     (ファイルをほぞんします) 파일을 저장해요.
   - 存(ゾン・ぞん) : この店をご存じですか。
     (このみせをごぞんじですか) 이 가게를 아세요?
   - 在(ザイ・ざい) : 現在、東京に住んでいます。
     (げんざい、とうきょうにすんでいます) 현재 도쿄에 살고 있어요.
   - 在(あ)る : 問題は制度に在ります。
     (もんだいはせいどにあります) 문제는 제도에 있어요. (보통 かな로 씀)

5. 又(또 우) 계열
   (39) 又 또 우
       訓 また
       오른손을 본뜬 글자 — 오른손은 옳고 바른 것이니 쓰고 또 쓴다
   (40) 双 두 쌍 = 又 + 又
       音 ソウ(そう) · 訓 ふた
       두 개의 손(又)이 하나의 쌍이다

   A: 双子の弟がいるんですか。
      (ふたごのおとうとがいるんですか)
      쌍둥이 동생이 있어요?
   B: はい。今度、又いっしょに来ます。
      (はい。こんど、またいっしょにきます)
      네. 다음에 또 같이 올게요.

   예문
   - 又(また) : 又会いましょう。
     (またあいましょう) 또 만나요. (보통 かな로 씀)
   - 双(ソウ・そう) : 双方の意見を聞きます。
     (そうほうのいけんをききます) 양쪽 의견을 들어요.
   - 双(ふた) : 双子の兄がいます。
     (ふたごのあにがいます) 쌍둥이 형이 있어요.

포인트
   犯 ↔ 氾 : 卩 앞이 犭(짐승)이면 죄를 범함, 氵(물)이면 물이 넘침 — 둘 다 ハン
   大 계열 마무리 — 爽(바람개비 㸚) · 器(그릇 네 개 㗊). 器는 うつわ(그릇)와 楽器·食器의 キ
   手 → 扌 → ナ : 손가락 5개 → 간략한 변 → 3개로 더 줄인 모양. 右·左·存·在의 ナ가 모두 손
   扌 + 夫 = 扶 フ / 扌 + 尺 = 択 タク / 扌 + 立 = 拉 ラ — 뒤 글자의 소리를 따라감
   右 ↔ 左 : 밥 먹는 손(口)은 오른손, 장인(工)의 손은 왼손. 左右 さゆう는 ユウ
   左 → 佐 : 왼손이 서툰 쪽이니 亻이 붙으면 돕는다(보좌)
   存 ↔ 在 : 말뚝(ナ+丨) 아래가 子면 아이가 있다(존재), 土면 땅이 있다(현재·소재)
   存 ソン·ゾン — 保存 ほぞん / ご存じ ごぞんじ
   又 = 오른손 — 双은 손 둘. 又(また)는 보통 かな로 씀
   읽기가 여러 개인 글자 — 犯 ハン·おかす / 爽 ソウ·さわやか / 器 キ·うつわ / 手 シュ·て·た / 右 ウ·ユウ·みぎ / 左 サ·ひだり / 存 ソン·ゾン / 在 ザイ·ある / 双 ソウ·ふた
