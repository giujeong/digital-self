26~29쪽. 25쪽의 走(달릴 주)·止(그칠 지)에서 발 이야기가 이어진다 — 일어나(起) 걷고(歩) 나아간다(捗). 발이 성을 돌면 둘레(韋)가 되고, 밤길에 발이 꼬이면 舛, 뒤처진 발은 夂. 손으로 치는 攵이 나오고, 입(口)과 사람(儿)이 만나 형(兄)이 되어 상황을 살피고(況) 빌고(呪) 이긴다(克). 입이 셋 모이면 물건(品), 성(囗)이 오래 버티면 굳다(固).

1. 走(달릴 주) 계열 — 25쪽에서 이어짐
   (57) 起 일어날 기 = 走 + 己
       音 キ(き) · 訓 お(きる)・お(こる)・お(こす)
       달리려면(走) 먼저 몸(己)부터 일으켜 세워라

   A: 毎朝何時に起きますか。
      (まいあさなんじにおきますか)
      매일 아침 몇 시에 일어나요?
   B: 六時です。起きてすぐ走ります。
      (ろくじです。おきてすぐはしります)
      6시요. 일어나서 바로 달려요.

   예문
   - 起(キ・き) : 朝早く起床します。
     (あさはやくきしょうします) 아침 일찍 기상해요.
   - 起(お)きる : 毎朝六時に起きます。
     (まいあさろくじにおきます) 매일 아침 6시에 일어나요.
   - 起(お)こる : 駅の前で事故が起こりました。
     (えきのまえでじこがおこりました) 역 앞에서 사고가 일어났어요.
   - 起(お)こす : 七時に子供を起こしてください。
     (しちじにこどもをおこしてください) 7시에 아이를 깨워 주세요.

2. 止(그칠 지) 계열 — 25쪽에서 이어짐
   (58) 歩 걸음 보 (步) = 止 + 少
       音 ホ(ほ)・ブ(ぶ)・フ(ふ) · 訓 ある(く)・あゆ(む)
       왼발(止)과 오른발(少)을 본뜬 글자 — 두 발이 번갈아 나가니 걸음. 少는 발 모양이지 '적다'가 아니다
   (59) 捗 진척 척 = 扌 + 歩
       音 チョク(ちょく) · 訓 はかど(る)
       걸어(歩)가서 손(扌)으로 거두어들인다 — 일이 앞으로 나아간다

   A: 進捗はどうですか。
      (しんちょくはどうですか)
      진척은 어때요?
   B: あまり捗らないので、少し歩いてきます。
      (あまりはかどらないので、すこしあるいてきます)
      잘 안 나가서, 좀 걷고 올게요.

   예문
   - 歩(ホ・ほ) : 駅まで徒歩で行きます。
     (えきまでとほでいきます) 역까지 걸어서 가요.
   - 歩(ブ・ぶ) : 歩合で給料をもらいます。
     (ぶあいできゅうりょうをもらいます) 성과급으로 월급을 받아요.
   - 歩(フ・ふ) : 将棋の歩を前に進めます。
     (しょうぎのふをまえにすすめます) 장기의 졸을 앞으로 보내요.
   - 歩(ある)く : 毎日一時間歩きます。
     (まいにちいちじかんあるきます) 매일 한 시간 걸어요.
   - 歩(あゆ)む : 二人は同じ道を歩んできました。
     (ふたりはおなじみちをあゆんできました) 두 사람은 같은 길을 걸어왔어요.
   - 捗(チョク・ちょく) : 工事の進捗を報告します。
     (こうじのしんちょくをほうこくします) 공사 진척을 보고해요.
   - 捗(はかど)る : 今日は仕事が捗りました。
     (きょうはしごとがはかどりました) 오늘은 일이 잘 진척됐어요.

3. 韋(둘레 위, 기본자) 계열
   韋 = 夂 + 口 + 夂 : 성(口)의 둘레를 도는 병사의 발(夂·夂) — 둘레. 짐승 몸의 둘레, 곧 가죽(가죽 위)도 뜻한다
   (60) 偉 클 위 = 亻 + 韋
       音 イ(い) · 訓 えら(い)
       사람(亻)이 짐승 가죽(韋)으로 만든 옷을 걸치니 몸이 커 보인다

   A: あの方はどなたですか。
      (あのかたはどなたですか)
      저분은 누구세요?
   B: 偉い先生です。偉大な発見をした人ですよ。
      (えらいせんせいです。いだいなはっけんをしたひとですよ)
      훌륭한 선생님이에요. 위대한 발견을 한 분이죠.

   예문
   - 偉(イ・い) : 偉大な作品を残しました。
     (いだいなさくひんをのこしました) 위대한 작품을 남겼어요.
   - 偉(えら)い : 一人で全部やって偉いですね。
     (ひとりでぜんぶやってえらいですね) 혼자 다 하다니 대단하네요.

4. 舛(어그러질 천, 기본자) 계열
   舛 = 夕 + 㐄 : 어두운 밤(夕)에는 길이 보이지 않아 발(㐄)이 틀어지기도 한다 — 틀어지다, 꼬이다, 어그러지다
   (61) 傑 뛰어날 걸 = 亻 + 舛 + 木
       音 ケツ(けつ)
       사람(亻)이 어렵게(舛) 발을 디뎌 가며 마침내 나무(木) 위 높은 곳까지 올라섰으니 뛰어난 사람

   A: 彼は本当に傑出した選手ですね。
      (かれはほんとうにけっしゅつしたせんしゅですね)
      그는 정말 걸출한 선수네요.
   B: ええ。今年の傑作はあのゴールです。
      (ええ。ことしのけっさくはあのゴールです)
      네. 올해의 걸작은 그 골이에요.

   예문
   - 傑(ケツ・けつ) : この映画は傑作です。
     (このえいがはけっさくです) 이 영화는 걸작이에요.

5. 夂(뒤져올 치, 기본자) 계열
   夂 = 아래쪽을 향한 발의 모양을 본뜬 글자 — '뒤처지다'. 攵(칠 복)과 매우 헷갈리니 주의
   (62) 条 가지 조 (條) = 夂 + 木
       音 ジョウ(じょう)
       나무(木) 줄기에 뒤처져(夂) 나오는 조그마한 가지 — 가지, 조목

   A: 契約の条件を教えてください。
      (けいやくのじょうけんをおしえてください)
      계약 조건을 알려 주세요.
   B: 第一条に書いてあります。
      (だいいちじょうにかいてあります)
      제1조에 쓰여 있어요.

   예문
   - 条(ジョウ・じょう) : 条件が合えば買います。
     (じょうけんがあえばかいます) 조건이 맞으면 살게요.

6. 攵(칠 복, 기본자) 계열
   攵 = 사람(⺊)의 손(又)으로 무언가를 친다 — 치다, 바로잡다. 夂(뒤져올 치)와 헷갈리기 쉽다
   (63) 改 고칠 개 = 己 + 攵
       音 カイ(かい) · 訓 あらた(める)・あらた(まる)
       자식(己)을 때리는(攵) 것은 그릇된 행실을 고쳐 개선하기 위함이다
   (64) 政 정사 정 = 正 + 攵
       音 セイ(せい)・ショウ(しょう) · 訓 まつりごと
       공공의 선에서 벗어나면 쳐서(攵) 바르게(正) 하는 것이 정사요 정치다

   A: 来月から政治の授業がありますね。
      (らいげつからせいじのじゅぎょうがありますね)
      다음 달부터 정치 수업이 있네요.
   B: はい。教科書が改訂されたそうです。
      (はい。きょうかしょがかいていされたそうです)
      네. 교과서가 개정됐대요.

   예문
   - 改(カイ・かい) : 時刻表が改正されました。
     (じこくひょうがかいせいされました) 시간표가 개정됐어요.
   - 改(あらた)める : 悪い習慣を改めます。
     (わるいしゅうかんをあらためます) 나쁜 습관을 고쳐요.
   - 改(あらた)まる : 年が改まりました。
     (としがあらたまりました) 해가 바뀌었어요.
   - 政(セイ・せい) : 政治に関心があります。
     (せいじにかんしんがあります) 정치에 관심이 있어요.
   - 政(ショウ・しょう) : 摂政が国を治めました。
     (せっしょうがくにをおさめました) 섭정이 나라를 다스렸어요.
   - 政(まつりごと) : 昔の政は神事と一つでした。
     (むかしのまつりごとはしんじとひとつでした) 옛날의 정사는 제사와 하나였어요.

7. 口(입 구) 계열
   (65) 口 입 구
       音 コウ(こう)・ク(く) · 訓 くち
       입을 본뜬 글자. 갑골문에서는 그릇에 무언가가 담긴 모습 — 음식이나 말을 담는다
   (70) 品 물건 품 = 口 + 口 + 口
       音 ヒン(ひん) · 訓 しな
       물건(口)이 가지런히 정리된 모습 — 정리를 잘해 두면 품이 달라 보인다

   A: この店は品物が多いですね。
      (このみせはしなものがおおいですね)
      이 가게는 물건이 많네요.
   B: ええ。入口に新商品もありますよ。
      (ええ。いりぐちにしんしょうひんもありますよ)
      네. 입구에 신상품도 있어요.

   예문
   - 口(コウ・こう) : 町の人口が増えています。
     (まちのじんこうがふえています) 동네 인구가 늘고 있어요.
   - 口(ク・く) : 先生の口調は優しいです。
     (せんせいのくちょうはやさしいです) 선생님 말투는 부드러워요.
   - 口(くち) : 口を大きく開けてください。
     (くちをおおきくあけてください) 입을 크게 벌려 주세요.
   - 品(ヒン・ひん) : 商品を棚に並べます。
     (しょうひんをたなにならべます) 상품을 선반에 진열해요.
   - 品(しな) : 品物を確認してください。
     (しなものをかくにんしてください) 물건을 확인해 주세요.

8. 儿(어진사람 인, 기본자) 계열 — 兄 가족
   儿 = 人의 변형으로, 사람을 나타내거나 특정 신체 부위를 강조할 때 쓴다
   (66) 兄 형 형 = 口 + 儿
       音 ケイ(けい)・キョウ(きょう) · 訓 あに
       사람(儿)의 입(口)을 강조한 형태 — 말에 힘이 있는 사람, 맏이
   (67) 況 상황 황 = 氵 + 兄
       音 キョウ(きょう)
       물(氵)이 부족하지 않은지 형(兄)이 상황을 살핀다
   (68) 呪 빌 주 = 口 + 兄
       音 ジュ(じゅ) · 訓 のろ(う)
       형(兄)이 입(口)으로 주문을 읽으며 비를 내려 주십사 신께 빈다 — 빌다, 저주하다
   (69) 克 이길 극 = 十 + 兄
       音 コク(こく)
       형(兄)이 많으면(十) 싸우지 않고도 이긴다

   A: 最近の状況はどうですか。
      (さいきんのじょうきょうはどうですか)
      요즘 상황은 어때요?
   B: 兄のおかげで、苦手な科目を克服しました。
      (あにのおかげで、にがてなかもくをこくふくしました)
      형 덕분에 약한 과목을 극복했어요.

   예문
   - 兄(ケイ・けい) : 父兄が学校に集まりました。
     (ふけいががっこうにあつまりました) 학부형이 학교에 모였어요.
   - 兄(キョウ・きょう) : 兄弟は三人です。
     (きょうだいはさんにんです) 형제는 셋이에요.
   - 兄(あに) : 兄は東京に住んでいます。
     (あにはとうきょうにすんでいます) 형은 도쿄에 살아요.
   - 況(キョウ・きょう) : 状況を説明してください。
     (じょうきょうをせつめいしてください) 상황을 설명해 주세요.
   - 呪(ジュ・じゅ) : 呪文を唱えます。
     (じゅもんをとなえます) 주문을 외워요.
   - 呪(のろ)う : 人を呪ってはいけません。
     (ひとをのろってはいけません) 남을 저주하면 안 돼요.
   - 克(コク・こく) : 困難を克服しました。
     (こんなんをこくふくしました) 어려움을 극복했어요.

9. 囗(에워쌀 위, 기본자) 계열
   囗 = 성이나 울타리로 에워싼 모양 — 口(입 구)보다 크게 쓴다. 団·困·因·囚의 바깥 네모가 이것
   (71) 固 굳을 고 = 囗 + 古
       音 コ(こ) · 訓 かた(める)・かた(まる)・かた(い)
       옛날(古)부터 성(囗)을 지킬 수 있었던 것은 성이 굳고 단단했기 때문이다. 古 = 십(十) 대에 걸쳐 입(口)으로 전해 온 옛일

   A: この箱、固くて開きません。
      (このはこ、かたくてあきません)
      이 상자 단단해서 안 열려요.
   B: 接着剤が固まったんですね。
      (せっちゃくざいがかたまったんですね)
      접착제가 굳었네요.

   예문
   - 固(コ・こ) : 固定した場所に置きます。
     (こていしたばしょにおきます) 고정된 자리에 둬요.
   - 固(かた)める : 土をしっかり固めます。
     (つちをしっかりかためます) 흙을 단단히 다져요.
   - 固(かた)まる : セメントが固まりました。
     (セメントがかたまりました) 시멘트가 굳었어요.
   - 固(かた)い : 固い約束をしました。
     (かたいやくそくをしました) 굳은 약속을 했어요.

포인트
   起 = 走(달리다) + 己(몸) — 달리기 전에 몸부터 일으킨다. おきる(일어나다)·おこる(일어나다, 사건)·おこす(일으키다)
   歩 = 止(왼발) + 少(오른발) — 少는 '적다'가 아니라 발. 日本은 歩, 한국은 步. 捗(はかどる)는 扌 + 歩 — 걸어가 손으로 거둔다 チョク
   韋 = 夂 + 口 + 夂 — 성 둘레를 도는 발. 偉는 사람 + 가죽옷 → 커 보인다 イ·えらい
   발 셋 구별 : 止(멈춘 발) / 夂(뒤처진 발, 条) / 舛(꼬인 발, 傑). 攵(칠 복)은 발이 아니라 손 — 改·政
   攵이 들어가면 고치고 다스린다 : 改 カイ·あらためる / 政 セイ·ショウ·まつりごと
   儿 = 사람. 兄 = 口 + 儿 — 입이 강조된 사람(맏이). 兄 가족은 소리가 다 다르다 — 況 キョウ / 呪 ジュ / 克 コク
   口 vs 囗 : 작으면 입, 크면 울타리. 品은 口 셋(ヒン·しな), 固는 囗 + 古(コ·かたい)
   반의어 : 兄 ↔ 弟 (형 ↔ 아우)
   읽기가 여러 개인 글자 — 起 キ·おきる·おこる·おこす / 歩 ホ·ブ·フ·あるく·あゆむ / 捗 チョク·はかどる / 偉 イ·えらい / 改 カイ·あらためる·あらたまる / 政 セイ·ショウ·まつりごと / 口 コウ·ク·くち / 品 ヒン·しな / 兄 ケイ·キョウ·あに / 呪 ジュ·のろう / 固 コ·かためる·かたまる·かたい
