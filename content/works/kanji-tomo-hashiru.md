22~25쪽. 21쪽의 又(또 우)에서 이어져 손 모양(寸·廾·彐·爪)을 지나 발(足·止·疋)로 넘어간다. 손으로 잡고 받들고 찾다가, 발로 멈추고 달린다.

1. 又(또 우) 계열 — 21쪽에서 이어짐
   (41) 友 벗 우 = ナ + 又
       音 ユウ(ゆう) · 訓 とも
       왼손(ナ)과 오른손(又)을 맞잡고 함께 가는 사람 — 벗
   (42) 抜 뺄 발 = 扌 + 友
       音 バツ(ばつ) · 訓 ぬ(く)・ぬ(ける)・ぬ(かす)・ぬ(かる)
       맞잡은 두 손(友) 사이로 또 다른 손(扌)이 들어와 하나를 뽑아낸다 — 발치

   A: 友達と山に行きましたか。
      (ともだちとやまにいきましたか)
      친구와 산에 갔어요?
   B: はい。疲れて、途中で力が抜けました。
      (はい。つかれて、とちゅうでちからがぬけました)
      네. 지쳐서 도중에 힘이 빠졌어요.

   예문
   - 友(ユウ・ゆう) : 友人と旅行に行きました。
     (ゆうじんとりょこうにいきました) 친구와 여행을 갔어요.
   - 友(とも) : 友と一緒に勉強します。
     (ともといっしょにべんきょうします) 벗과 함께 공부해요.
   - 抜(バツ・ばつ) : 歯医者で抜歯しました。
     (はいしゃでばっししました) 치과에서 이를 뽑았어요.
   - 抜(ぬ)く : 庭の草を抜きました。
     (にわのくさをぬきました) 마당의 풀을 뽑았어요.
   - 抜(ぬ)ける : 髪の毛が抜けます。
     (かみのけがぬけます) 머리카락이 빠져요.
   - 抜(ぬ)かす : 朝ご飯を抜かしました。
     (あさごはんをぬかしました) 아침을 걸렀어요.
   - 抜(ぬ)かる : 抜かりなく準備しました。
     (ぬかりなくじゅんびしました) 빈틈없이 준비했어요.

2. 寸(마디 촌) 계열
   (43) 寸 마디 촌
       音 スン(すん)
       손(十)목 끝에서 맥박이 뛰는 곳(丶)까지 — 한 뼘, 한 마디. 손·마디·헤아림을 뜻한다
   (44) 団 둥글 단 = 囗 + 寸
       音 ダン(だん)・トン(とん)
       손(寸)을 잡고 둥글게(囗) 모인 사람들 — 단체

   A: 布団の寸法はどのくらいですか。
      (ふとんのすんぽうはどのくらいですか)
      이불 치수가 어느 정도예요?
   B: 団体用なので、少し大きいです。
      (だんたいようなので、すこしおおきいです)
      단체용이라 조금 커요.

   예문
   - 寸(スン・すん) : 寸法を測ってください。
     (すんぽうをはかってください) 치수를 재 주세요.
   - 団(ダン・だん) : 団体で旅行します。
     (だんたいでりょこうします) 단체로 여행해요.
   - 団(トン・とん) : 布団を干しました。
     (ふとんをほしました) 이불을 널었어요.

3. 廾(받들 공, 기본자) 계열
   廾 = 두 손(ナ·又)을 위로 올려 무언가를 바친다 — 받들다
   (45) 共 함께 공 = 廾 + 廾
       音 キョウ(きょう) · 訓 とも
       받드는 손(廾)이 둘 — 손들이 모여 함께 일한다
   (46) 供 이바지할 공 = 亻 + 共
       音 キョウ(きょう)・ク(く) · 訓 そな(える)・とも
       사람(亻)들이 함께(共) 일하며 공동체에 이바지한다

   A: 私たちの共通点は何でしょう。
      (わたしたちのきょうつうてんはなんでしょう)
      우리 공통점이 뭘까요?
   B: 子供のころ、同じ町に住んでいたことです。
      (こどものころ、おなじまちにすんでいたことです)
      어릴 때 같은 동네에 살았던 거요.

   예문
   - 共(キョウ・きょう) : 共通の趣味があります。
     (きょうつうのしゅみがあります) 공통 취미가 있어요.
   - 共(とも) : 家族と共に暮らしています。
     (かぞくとともにくらしています) 가족과 함께 살고 있어요.
   - 供(キョウ・きょう) : 情報を提供します。
     (じょうほうをていきょうします) 정보를 제공해요.
   - 供(ク・く) : 先祖の供養をします。
     (せんぞのくようをします) 조상을 공양해요.
   - 供(そな)える : お墓に花を供えました。
     (おはかにはなをそなえました) 묘에 꽃을 바쳤어요.
   - 供(とも) : 子供と公園に行きます。
     (こどもとこうえんにいきます) 아이와 공원에 가요.

4. 爪(손톱 조) 계열
   (47) 爪 손톱 조 (부수로 쓰면 爫)
       訓 つめ・つま
       손가락을 세 개로 줄여 그린 손. 혼자 쓰이면 손톱, 부수(爫)로 쓰이면 손

   A: 爪が長いですね。
      (つめがながいですね)
      손톱이 길네요.
   B: はい。爪先まで伸びたので、今夜切ります。
      (はい。つまさきまでのびたので、こんやきります)
      네. 끝까지 자라서 오늘 밤 깎을게요.

   예문
   - 爪(つめ) : 爪を切りました。
     (つめをきりました) 손톱을 깎았어요.
   - 爪(つま) : 爪先で立ちます。
     (つまさきでたちます) 발끝으로 서요.

5. 彐(돼지머리 계, 기본자) 계열
   彐 = 손가락을 세 개로 줄여 그린 손 — 이름은 돼지머리지만 돼지와는 상관없다
   (48) 尋 찾을 심 = 彐 + 工 + 口 + 寸
       音 ジン(じん) · 訓 たず(ねる)
       어두운 곳에서 왼손(彐工)과 오른손(彐口)으로 더듬어(寸) 물건을 찾는다

   A: すみません、駅への道を尋ねてもいいですか。
      (すみません、えきへのみちをたずねてもいいですか)
      실례지만, 역 가는 길을 여쭤봐도 될까요?
   B: はい。この道をまっすぐ行ってください。
      (はい。このみちをまっすぐいってください)
      네. 이 길로 쭉 가세요.

   예문
   - 尋(ジン・じん) : 警察で尋問を受けました。
     (けいさつでじんもんをうけました) 경찰에서 심문을 받았어요.
   - 尋(たず)ねる : 道を尋ねました。
     (みちをたずねました) 길을 물었어요.

6. 足(발 족) 계열
   (49) 足 발 족 (변으로 쓰면 ⻊)
       音 ソク(そく) · 訓 あし・た(りる)・た(る)・た(す)
       무릎(口)까지 포함한 발 — 엄지발가락·발 안쪽 선·바깥 선·발목이 다 들어 있다
   (51) 促 재촉할 촉 = 亻 + 足
       音 ソク(そく) · 訓 うなが(す)
       사람(亻)이 발(足)을 가리키며 바삐 움직이라고 재촉한다
   (52) 捉 잡을 착 = 扌 + 足
       音 ソク(そく) · 訓 とら(える)
       가지 못하게 손(扌)으로 발(足)을 착 붙잡는다

   A: 時間は足りますか。
      (じかんはたりますか)
      시간 충분해요?
   B: いいえ。先生に早くするように促されました。
      (いいえ。せんせいにはやくするようにうながされました)
      아니요. 선생님이 빨리 하라고 재촉하셨어요.

   예문
   - 足(ソク・そく) : 靴を一足買いました。
     (くつをいっそくかいました) 신발을 한 켤레 샀어요.
   - 足(あし) : 長く歩いて足が痛いです。
     (ながくあるいてあしがいたいです) 오래 걸어서 발이 아파요.
   - 足(た)りる : 時間が足りません。
     (じかんがたりません) 시간이 부족해요.
   - 足(た)る : 信頼するに足る人です。
     (しんらいするにたるひとです) 믿을 만한 사람이에요.
   - 足(た)す : 塩を少し足してください。
     (しおをすこしたしてください) 소금을 조금 더 넣어 주세요.
   - 促(ソク・そく) : 健康を促進する運動です。
     (けんこうをそくしんするうんどうです) 건강을 촉진하는 운동이에요.
   - 促(うなが)す : 早く帰るように促しました。
     (はやくかえるようにうながしました) 일찍 돌아가라고 재촉했어요.
   - 捉(ソク・そく) : 敵の位置を捕捉しました。
     (てきのいちをほそくしました) 적의 위치를 포착했어요.
   - 捉(とら)える : 問題の本質を捉えます。
     (もんだいのほんしつをとらえます) 문제의 본질을 파악해요.

7. 止(그칠 지) 계열
   (50) 止 그칠 지
       音 シ(し) · 訓 と(まる)・と(める)
       무릎을 뺀 발 — 멈추어 서 있는 발. (걷고 있는 발은 ⺊ 모양으로 쓴다)
   (53) 正 바를 정 = 一 + 止
       音 セイ(せい)・ショウ(しょう) · 訓 ただ(しい)・ただ(す)・まさ
       정처 없이 떠도는 것보다 한(一) 곳에 머무는(止) 것이 바르다
   (54) 企 꾀할 기 = 人 + 止
       音 キ(き) · 訓 くわだ(てる)
       다음 기회를 꾀하려면 사람(人)은 잠시 멈추어야(止) 한다
   (55) 渋 떫을 삽 = 氵 + 止 + ⺍
       音 ジュウ(じゅう) · 訓 しぶ・しぶ(い)・しぶ(る)
       물(氵)이 사방(⺍)에 고여 발이 멈춘(止) 상태 — 가지 못하니 떫고 막힌다 (⺍ 모양은 일본식 한자에서만 쓰는 요소)

   A: 雨で試合が止まりましたね。
      (あめでしあいがとまりましたね)
      비로 시합이 멈췄네요.
   B: 正しい判断だと思います。道も渋滞していますし。
      (ただしいはんだんだとおもいます。みちもじゅうたいしていますし)
      옳은 판단이라고 생각해요. 길도 막히고요.

   예문
   - 止(シ・し) : 雨で試合が中止になりました。
     (あめでしあいがちゅうしになりました) 비로 시합이 중지됐어요.
   - 止(と)まる : 電車が止まりました。
     (でんしゃがとまりました) 전철이 멈췄어요.
   - 止(と)める : 車をここに止めてください。
     (くるまをここにとめてください) 차를 여기에 세워 주세요.
   - 正(セイ・せい) : 正解は三番です。
     (せいかいはさんばんです) 정답은 3번이에요.
   - 正(ショウ・しょう) : お正月に家族が集まります。
     (おしょうがつにかぞくがあつまります) 설에 가족이 모여요.
   - 正(ただ)しい : 正しい答えを書いてください。
     (ただしいこたえをかいてください) 바른 답을 써 주세요.
   - 正(ただ)す : 姿勢を正してください。
     (しせいをただしてください) 자세를 바로 해 주세요.
   - 正(まさ) : 正にその通りです。
     (まさにそのとおりです) 바로 그 말대로예요.
   - 企(キ・き) : 大きな企業に就職しました。
     (おおきなきぎょうにしゅうしょくしました) 큰 기업에 취직했어요.
   - 企(くわだ)てる : 新しい計画を企てています。
     (あたらしいけいかくをくわだてています) 새 계획을 꾀하고 있어요.
   - 渋(ジュウ・じゅう) : 道路が渋滞しています。
     (どうろがじゅうたいしています) 도로가 막혀요.
   - 渋(しぶ) : 柿の渋を抜きます。
     (かきのしぶをぬきます) 감의 떫은맛을 빼요.
   - 渋(しぶ)い : このお茶は渋いです。
     (このおちゃはしぶいです) 이 차는 떫어요.
   - 渋(しぶ)る : 彼は返事を渋りました。
     (かれはへんじをしぶりました) 그는 대답을 망설였어요.

8. 疋(발 소, 기본자) 계열
   疋 = 발(足)을 간략히 그린 글자
   (56) 走 달릴 주 = 土 + 疋
       音 ソウ(そう) · 訓 はし(る)
       발(疋)을 크게 벌려 뛰어가는 사람(土) — 글의 머리에 놓인 土는 흙이 아니라 사람(大)

   A: 毎朝走っていますか。
      (まいあさはしっていますか)
      매일 아침 달려요?
   B: はい。来月はマラソンを完走したいです。
      (はい。らいげつはマラソンをかんそうしたいです)
      네. 다음 달엔 마라톤을 완주하고 싶어요.

   예문
   - 走(ソウ・そう) : マラソンを完走しました。
     (マラソンをかんそうしました) 마라톤을 완주했어요.
   - 走(はし)る : 駅まで走りました。
     (えきまではしりました) 역까지 달렸어요.

포인트
   友 = ナ(왼손) + 又(오른손) — 손에 손. 抜은 맞잡은 손(友)에서 하나를 손(扌)으로 뽑아냄 バツ
   寸 = 손목의 한 마디. 団은 囗 + 寸 — 団体 ダン, 布団 トン
   廾 = 위로 올린 두 손 → 共(함께) キョウ·とも → 供(사람 + 共) 바치다 そなえる. 子供의 ども도 とも
   손을 세 손가락으로 줄인 모양 — ナ(右·左·友), 又, 彐, 爪(爫) 모두 손
   尋 = 彐 + 工 + 口 + 寸 — 두 손으로 더듬어 찾는다. たずねる: 尋ねる(묻다) / 訪ねる(방문하다)
   足 vs 止 : 무릎(口)까지 있으면 足, 무릎을 빼면 止. 足이 들어가면 ソク — 促·捉
   止가 들어간 글자는 소리가 제각각 — 正 セイ·ショウ / 企 キ / 渋 ジュウ
   疋 = 足의 간략형. 走 = 土(사람) + 疋 — 머리에 놓인 土는 사람
   반의어 : 正 ↔ 誤 (바르다 ↔ 그르치다)
   읽기가 여러 개인 글자 — 友 ユウ·とも / 抜 バツ·ぬく·ぬける·ぬかす·ぬかる / 団 ダン·トン / 共 キョウ·とも / 供 キョウ·ク·そなえる·とも / 爪 つめ·つま / 尋 ジン·たずねる / 足 ソク·あし·たりる·たる·たす / 促 ソク·うながす / 捉 ソク·とらえる / 止 シ·とまる·とめる / 正 セイ·ショウ·ただしい·ただす·まさ / 企 キ·くわだてる / 渋 ジュウ·しぶ·しぶい·しぶる / 走 ソウ·はしる
